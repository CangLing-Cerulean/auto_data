# 训练反馈采样探索

## 证据边界与接续

本轮仅训练内部开发反馈，未开展完整验证或测试，也未采用新默认。打乱对照使用胜者冻结的逐阶段概率，在相同状态×月份内置换，保留全部概率值和单元总质量；对照不利用自身模型重新评分。

评分方案额外执行五遍候选窗口前向，计入原墙钟预算。对照复用冻结分数，因此只有反向更新数和训练呈现次数相同，不能称总计算量完全相同。每阶段源窗口概率、训练误差、实际次数、评分模型与可续训模型均已保存。

当前结果未建立该训练反馈规则的跨时段优势。停止此配方，不继续扫混合比例或评分频率；下一步应登记不同的数据价值假设，默认继续全部保留、均匀采样。
