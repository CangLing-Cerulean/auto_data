# 数据特征与预测不足直接探索

2026年10月9日，用户要求暂时不由自组Agent发现方案，先由当前研究助手直接探索。当前阶段用于建立诊断方法、处理假设和信号评价依据；属于有研究者指导的开发探索，不能计入未来自主Agent成功率。已有Agent工程和经验库保留，发现实验暂缓。

## 本次诊断

复用S000、S005、S010三个原固定DLinear基线的最佳检查点，不训练、不调用模型API。在完整开发验证的300535个合法窗口上重新推理，并核对已有总体、分月及分通道成绩。持久性预测仅作为诊断参照：八个预测位置均取最后一次观测，不替换主模型。

所有输入特征仅使用窗口前32条观测。变化分组阈值、持续时长分组阈值只在T拟合；D用于开发误差反馈，窗口和真值完整保留。基础数据、协议、源码、检查点和历史结果的哈希在运行前后校验。服务器没有测试文件，本次采用manifest约束的T/D哈希、行数和时间边界校验；原完整verify_dataset校验此前已完成，不为重跑完整校验向探索服务器上传测试。

| 分解 | 预先固定的定义 | 作用 |
|---|---|---|
| 输入变化 | 标准化后相邻观测绝对变化跨15通道均值；T四分位和90百分位划分低、中、高 | 复算已有观察，同时报告覆盖和误差贡献 |
| 数字信号切换 | 输入31个相邻间隔内无切换、仅早期切换、最后4个间隔有切换 | 检查切换邻近性与误差的关系 |
| 模拟信号静止 | 前7列在全部32条输入中均精确不变 | 检查采集现象与预测表现，不能自动标记故障 |
| 窗口实际时长 | 输入首末时间差；T四分位和90百分位划分 | 区分记录步长与物理时间跨度 |
| 单通道输入恒定 | 该通道输入32条完全相同，分别统计恒定/变化 | 检查误差是否发生在无历史变化时 |
| 事后未来变化 | 八个目标中是否出现不同于输入末值的记录 | 解释误差来源；使用目标，禁止作为可部署筛选特征 |

报告每组T/D窗口数、覆盖比例、三种子NMSE/NMAE、有符号残差、误差贡献，以及与持久性预测的差距。分天复算用于描述持续性，不把重叠窗口或三个模型种子当作独立统计样本，不在本次宣布显著性。组间重叠不相加。

## 解释和下一步

先区分三种证据：可复算的数据现象、稳定预测不足、受控干预支持的处理方向。高误差不自动意味着加采样，输入恒定不自动意味着删数据。未来变化分组可解释误差，但不能写入训练采样规则。结果后再登记处理假设、预期局部收益、总体代价、竞争解释、匹配控制和否定条件，再开始新的训练。

本次不启动历史补充队列，不更换模型结构，不用已揭示的旧测试选择方案。新资料位置待提供，独立任务和最终评价仍待另行登记。
