# 按通道历史工况分布重加权：运行前登记

背景：新文献调查与A005表明，原DLinear同一仿射函数空间的全训练最小二乘诊断NMSE为训练0.27139151、验证0.28533821；原Adam基线训练0.27361244、验证0.28801676。这不是正式收益或泛化上限，但原均匀目标的充分拟合只给出约0.93%的验证差距。因此继续追求均匀目标方差下降不太可能直接解释大幅改善。

依据：[Huang等，NIPS2006](https://proceedings.neurips.cc/paper/2006/hash/a2186aa7c086b46ad4e8bf81e2a3a19b-Abstract.html)通过分布匹配调整权重；[Sugiyama等，JMLR2007](https://www.jmlr.org/papers/volume8/sugiyama07a/sugiyama07a.pdf)明确协变量漂移假设要求输入分布变化而条件分布不变。本方案使用离散状态频率比，是项目自定义的训练历史代理，不是KMM/IWCV复现，也不声称条件稳定假设已经成立。正式验证/测试输入均不用于拟合频率或权重。

假设：独立通道DLinear每列只依赖本列输入，用一个全窗口权重会同时改变其他14列的拟合目标。按通道匹配近期输入状态，可避免这种无关列联动，并以严格后续时段重训验证迁移效果。

定义：对可见历史中的全部合法32→8窗口，每列取输入末值、首末差符号（下降/不变/上升）、输入内是否发生任意值变化。末值以全部可见合法窗口的20/40/60/80百分位为分界（重复分界合并）。三者联合为状态；只使用32条输入，不看其8条标签。参考分布是可见历史最后20%原始行内完整窗口的输入状态分布。每个状态r=近期频率/全部频率；原始权重min(4,0.5+0.5*r)，再除以该列全窗口平均权重。所有窗口保留、均匀抽样，逐通道MSE乘对应权重，每列期望权重1。不扫描分箱、近期长度或混合系数。

模型、任务、Adam、3000步、768000呈现、prefix标准化和终点评价与T000/T005不变。改变的研究变量是逐窗口逐通道损失权重，不更换模型；验证指标仍所有窗口所有15列等权原NMSE。权重拟合使用原训练历史，内部未来探针不参与权重拟合。

先只T009_prefix60_state_balance，配对T000。若内部未来NMSE改善至少1%，才登记80%原点复核；两原点均至少1%才登记正式验证和相同月份内权重打乱控制。否则停止该配方，不搜索阈值。此前粗删除、梯度方向降权、去重、动态重要性采样各自失败/小幅结果保留，不改门槛。

保存源行、每列状态/权重及频数、参考边界、ESS、实际抽取次数、协议和辅助代码身份。核验未来未参与频率估计、每列平均权重1、抽样顺序与全量相同。所有成本沿用原7200秒预算，无测试访问。
