# 首轮固定研究协议

用户于 2026-09-26 确认。本文件及 protocol.json 取代 startup.md 中未确认的协议提案状态。

任务为 15 个传感器的多变量时序预测：32 条历史预测后续 8 条。采用各通道独立线性层的 DLinear，移动平均核 25、端点复制填充、PyTorch Linear 默认初始化。结构依据官方 LTSF-Linear 的 models/DLinear.py，未改变模型主体。基线随机种子 2026；重要收益使用 2027、2028 配对确认。

标准化使用原始训练段的逐列均值和总体标准差；零方差列统一采用 1 作为尺度。所有方案沿用同一尺度。NMSE 是逐元素平方误差除以训练标准差平方后的均值，NMAE 是逐元素绝对误差除以训练标准差后的均值，对所有窗口、预测步、变量等权平均。NMSE 为主指标，NMAE 为次指标；同时保留逐变量与分组结果。

训练/验证各自在自己的分区内以步长 1 构造窗口。40 条记录内部任意相邻间隔超过 30 秒即不属于该固定任务的合法窗口；不填补时间点。不跨分区。此规则在观察验证预测效果前冻结，后续不得因困难程度修改验证窗口。

Adam，学习率 0.001，无权重衰减，批量 256，3,000 更新步；每轮呈现 768,000 窗口，均匀有放回采样。每 500 步评估所有合法验证窗口；选择验证 NMSE 最低的检查点，平局选更早检查点。不使用提前停止或动态学习率。后续数据方案保持更新预算、模型和指标不变。

分组按预测起始月份，以及输入历史的平均绝对标准化相邻变化分组；高变化阈值采用合法训练窗口第 90 百分位，仅使用输入历史。报告持久性预测参照。分组窗口数、合法窗口数、尺度及版本指纹均记录。

最多 3 轮基于反馈的数据方案，不要求用满；加上基线、必要配对确认，总累计远程运行时间限制为 7,200 秒（包含各训练进程的数据准备、验证等时间，保守计入 GPU 预算）。新一轮研究可另行获准增加预算，不能静默重置。

每次实验保留身份清单、协议/代码快照、环境版本、数据审计、训练轨迹、最新与最佳检查点和最终验证结果。最新检查点包含优化器及随机数状态，可按原 run ID 恢复；已完成实验禁止覆盖。源代码无 Git 提交时以 SHA256 和完整源码快照标识，不擅自提交。

测试 CSV 不上传远程。开发期间不读取测试分布，不计算测试预测指标。当前阶段以可接续的开发研究结果结束，不自动解封最终测试集。
