## 内容与证据边界

逐次记录来自本地权威state的134个completed_run_ids对应的result.json。仅将批准的结果JSON复制到独立sources目录；未读传感器CSV、test_result.json或检查点。每条记录保存原结果文件哈希、配方、模型、seed/原点等已有身份字段、评价范围、分组和逐通道指标、步数及计时。结果未提供的信息不补造；原始协议/代码哈希是进一步核对配置的入口，不把缺失参数假装成已知。

identity中的字段按原记录保留；模型名缺省的主训练按原固定DLinear研究登记标注为original_DLinear，缺省辅助训练标为auxiliary。该分类不是对全部134份模型源码的重新审计，完整结构与训练参数仍需按原协议及源码核对。

开发验证、训练内部前向评价、辅助评分器和模型结构变化分别标明。模型改造记录只作为历史背景，不能计入当前固定DLinear数据处理收益。不同模型或评价范围的绝对指标不能直接排序为同一任务的最佳方案。

10条摘要保留既有出处、原文范围及条件限制，统一标记为人工整理、解释待核验。原文里的因果描述仍是历史作者的判断，不自动成为真相。摘要关联的运行ID由原文显式引用生成，只是查询链接，不自动证明两次实验为匹配控制。当前没有完整覆盖134次运行各自的动作前假设和处理代码；已完整覆盖的是逐次结果，另由现有10条摘要提供部分诊断与决策上下文。

## 保留探索空间

- 经验检索不筛除处理候选，不生成方法族禁用名单，也不自动选择方向。
- 观察与解释分开；失败只约束已测配方、模型、seed和评价范围，不外推为整个方法族无效。
- Agent可以质疑旧解释、改变条件或提出复现；经验工具不因历史失败拒绝查询或提交。当前执行器既有的覆盖、去重和历史删除掩码重合检查仍属于原开发协议；有意复现须与该探索协议区分登记。
- 不强制Agent先读经验或照历史摘要行动。新增版本移除了开发提交对“必须检索经验”的前置条件；旧工程覆盖要求和既有结果不改写。
- 保留有经验、无经验、仅其他任务经验三种工具访问方式，以供正式对照登记。新任务按数据集家族排除同源历史，即便版本号不同也不能读入本任务答案。
- 每轮冻结库版本，不在独立搜索之间追加同批成功答案；当前运行自己的诊断和反馈仍存入自身证据链。

这些设计说明经验库没有新增方法族硬限制，不能证明其行为影响为零。提示内容和检索排序仍可能影响Agent方向，需比较有效信号率、改进比例、成本、重复及新颖性后才能评价。当前工具层的信息过滤不构成root原生代码的强文件访问隔离，未据此宣称正式盲态实验已完成。
