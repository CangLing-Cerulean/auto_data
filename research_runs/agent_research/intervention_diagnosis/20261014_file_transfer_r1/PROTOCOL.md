# 源文件隔离下的训练记录删除响应

2026-10-14，事前登记协议；运行仍须通过代码/任务准备验收及逐阶段激活。本阶段沿固定DLinear和固定M1研究，不恢复已关闭的MetroPT3/SKAB时间半组批次，不增加噪声代理，不调整旧阈值。前序409次完整训练及全部失败保持。

## 研究问题及适用范围

当拟合、检查点选择和评分分别来自不同实验记录时，能否在完整重训之前预测“移除某一训练记录”的响应，并比未校正代理、SOURCE固定公式适配、真实短训练及便宜规则选择更好的训练数据？干预单位是自然来源文件在基础train中的全部片段；它不是传感器变换，也不假定被移除记录错误或异常。

SKAB是已接触的开发来源。基础train含23个源文件片段、32802行，部分片段不是完整原始实验。这里只改变基础train内部的任务角色，不重划基础数据，不访问基础validation/test或旧D。新候选重训响应可以事前锁定，但不能将这些记录、三个任务或单一设备称独立新来源、研究全程未见数据或最终评估。预测仍是在单个记录内部由32个观测预测后8个观测；跨文件角色不代表时间先后或跨设备泛化。文件时间有重叠，文件身份互斥本身不证明数值内容或物理实验独立。

## 文件组与任务

文件全集严格取`data/skab_v1/manifest.json`中`splits[name=="train"].series_coverage[].series_id`，其原字符串必须与基础表`source_file`完全相等，不按传感器值、历史响应、异常名称或目录类别筛选。按SHA256(UTF-8编码的`file-transfer-r1|`+完整series_id)的64位小写十六进制字符串升序，摘要完全相同时按series_id Unicode码点升序；排序位置从0开始，组号为rank mod 3。固定得到8、8、7文件三个组，不尝试其他盐值或分组。

三个任务同时登记：F0的A/B/C为组0/1/2；F1为组1/2/0；F2为组2/0/1。每个文件进入一次A、一次B、一次C，所有任务均使用全部8传感器。角色划分在加载传感器表前公开锁定；不因随后行数、分布、父成绩或候选预测不理想而重分组。

每个角色按source_file、source_row排序并保留原基础train行号、源行号和时间戳。40行窗口必须位于同一文件/角色，source_row逐一连续，时间严格递增且每个相邻间隔≤30秒；步长1，不插值、不生成记录。每角色所有合法窗口参与计算，A不再按时间半组排除跨中点窗口。必须每源片段至少有1个合法窗口、A/B/C各至少256窗口、任一单文件删除后A至少256窗口；失败则停止准备，不删文件或重分组补救。

标准化只用该任务全部A原始行的float64均值/总体标准差，零标准差置1；标准化值float32。所有候选保留同一父标准化。本研究的删除仅指训练抽样支持，被删文件仍参与已固定均值/标准差的拟合。B/C评分为全部窗口、全部通道与预测步的float32前向误差，在float64汇总NMSE/NMAE；每文件辅助指标另报，不用其改变主度量。另记录窗口实际预测时间跨度。

## 完整动作菜单与运行矩阵

父PARENT在全部A窗口均匀有放回采样。对A内每一个源文件f登记一个DROP动作：该文件全部窗口概率0，其余窗口概率1/(N−n_f)，损失权重恒1。输入、目标及B/C评分权重不变；没有软倍率、二次筛选或候选子集。动作ID按源文件名升序编号，保留明确映射；比较和并列规则也用此固定顺序。文件名仅用于溯源、隔离和自然单位删除，不作为模型特征或异常标签。

逆CDF的浮点实现将累计和除以其末项，再从最后一个正概率位置起统一置1；所有零概率平台保持不变，避免尾部删除窗口因舍入获得概率。随机数流和Adam更新公式保持固定。此工程修正发生于任何传感器表加载和训练之前，旧冻结运行不追溯修改。

F0/F1/F2分别8/8/7动作，共23个任务动作。三个种子2026102001/02/03，每任务父子共同初始化、共同seed+1000的NumPy均匀随机数流；各动作逆CDF产生的实际样本可不同。固定DLinear逐通道，32→8、核25、Adam lr=.001/weight_decay=0、batch256、完整3000步，原骨干与`response_proxy.py`不改。K={500,1000,1500,2000,2500,3000}，只按B最早最低NMSE选点，C给出响应。

新ID统一FTR1前缀，独立目录。完整父9次、完整子69次，若全矩阵完成累计487。代理父9次、代理子69次、SHORT69次另列；禁止把它们计为完整训练。SHORT最多2500步，不允许提前达到完整3000步标签。复用数学实现不复用旧任务父模型、启动锁或运行ID。

## 比较方法与预测

M1仍是每个K的real_parent+(proxy_child−proxy_parent)，RAW为未校正proxy_child；都独立按B选K、C评分，相对真实父B最佳模型计算改善。代理使用全A的μ=p精确矩梯度和原Adam有限轨迹，不加入梯度噪声修正。

SOURCE使用已验收的单一公式适配：500步分段、段末真实父参数/Adam二阶状态、偏差校正对角P、父完整二次曲率及标准归一化概率梯度差；不调分段、P、阻尼或有限干预尺度。逐K输出父+δ，转float32，以同一B/C规则评分。这是固定公式适配，不称作者Adam实现复现；源码必须绑定既有工程验收哈希。

SHORT从同一原初始化、按候选p训练到下面预先校准的固定K前缀。与完整训练相同的500步网格中按B选点，C评分；不延长、不因候选损失动态分配预算。PARENT始终保留完整父。另登记两种便宜决策：SIZE_DROP删除A合法窗口最多的文件；LOSS_DROP删除完整父B最佳模型在A上每文件平均NMSE最高的文件。LOSS_DROP先每文件对三个种子求均值，不用文件长度加权；完全并列按动作顺序。两种便宜策略不输出伪造的响应预测，也不根据真实子标签决定是否执行；其额外计算成本和可能伤害如实报告。

每种数值预测方法先对任务动作的三个种子改善求均值，选预测改善最大且≥1%的动作，否则PARENT；并列按固定动作顺序。类别保持>+0.25% improve、<−0.25% hurt，其余unchanged。所有方法均使用同一个完整菜单，禁止选择有利种子或文件。

## 固定步数短训校准及成本

先只运行9个真实父、9个代理父，并对每个父做一次六检查点M1恒等动作评分，测量其实际端到端成本。真实父每500步记录包含初始化、训练、检查点保存、B/C评分与必要资产写入的前缀耗时；该计时方式与未来SHORT前缀一致。校准只用于成本，不根据父成绩更改角色、动作或科学门槛。

对任务t、动作数k，令P为三个代理父总耗时最大值，S为三个恒等动作六点M1评分总耗时最大值，c=(1+1/k)P+S。SHORT固定步数选{500,1000,1500,2000,2500}中最小的j，使三个真实父在j处的前缀耗时最小值≥1.25c。没有满足的j即在候选之前停止。额外尾部成本不从该前缀预算扣除。所有任务的j、原始计时和父资产先提交GitHub并核对，然后才运行候选预测。

这是对照计算量更充足的固定前缀比较，不称严格等秒预算。M1每任务种子的选择成本包含代理父、全部代理子和全部M1评分；SHORT包含该组全部SHORT完整端到端耗时。M1/RAW所需特征、矩的计算、保存与哈希均在各自代理成本内，不计作免费共同准备。预测锁前必须逐组满足M1实际选择成本≤SHORT实际选择成本，否则停止本批，不再增加SHORT步数补救。SOURCE从A独立计算自己需要的矩/曲率并计时，不能免费借用另一个方法已计算的矩；RAW计自己的代理子和评分，SIZE_DROP/LOSS_DROP计各自额外决策成本。共同任务准备/载入、真实父、校准、传输与审计开销全部独立入账，冷启动和增量成本分列，未知成本保留null。

完整标签后另检验M1每任务种子选择成本≤该组全部完整子实际端到端成本的50%；不可用父耗时估计代替实际穷举成本。所有方法均报告成本—误差—选择收益，不因SOURCE便宜便宣称M1整体更高效。

冷启动分两种口径：`cold_required_computation`在各方法增量成本上加入分摊的共同准备/载入和真实父训练；`cold_registered_execution`再加入本实验校准所支付的恒等动作评分和代理父，M1已计代理父不重复计入。分摊值不是各方法单独启动的实测。真实研究总耗时另按互斥执行区间记账，复用资产不重复求和；阶段日志、审计与传输也单列，不以方法比较的分摊账目冒充实际总消耗。

## 顺序、验收与停止

文件清单/任务与菜单锁定 → 代码与准备/数值工程验收 → 源码协议同步 → 父/校准与独立审计 → 校准同步 → 全部69代理子/69SHORT及SOURCE/便宜策略预测 → 成本审计与全部预测/推荐GitHub锁 → 全69完整子 → 独立最终审计/报告/资产同步。

完整子标签前检查决策可辨别性：若M1与RAW、SOURCE、SHORT、PARENT、SIZE_DROP或LOSS_DROP中的任一基线在全部三个任务上推荐完全相同，则任何真实标签下二者平均收益相同，原+0.10pp增量条件不可能满足；记录并停止，不消耗完整标签，此时响应精度仍未知。否则必须运行全部69格，不按预测误差、收益或方法分歧删项。任何工程/完整性故障停止当前队列，保留失败与全部消耗，同ID不覆盖重跑。

主精度为任务等权MAE：先每任务对其全部动作求三种子均值预测/真值之绝对误差均值，再平均三个任务。同时报告全部23格等权、每任务、每种子和不稳定格。M1须≤0.8×最佳RAW/SOURCE/SHORT主MAE，绝对至少少0.05pp，对同一个最佳动态精度基线至少2/3任务不劣。

决策要求：M1三个任务平均真实推荐改善≥max(RAW,SOURCE,SHORT,PARENT,SIZE_DROP,LOSS_DROP)+0.10pp，且每任务推荐平均改善≥−0.25%。报告包含父的原始oracle、按1%门槛筛选的oracle、两种遗憾、有效动作覆盖及伤害推荐；不混淆原始正收益和采用资格。只有完整性、精度、决策与成本均通过才通过本有限开发问题，不推断独立跨源确认或LLM反馈因果优势。未通过不增加本轮文件组、种子、动作或修改门槛补救。
