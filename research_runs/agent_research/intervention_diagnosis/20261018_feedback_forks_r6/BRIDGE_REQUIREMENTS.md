# 从条件响应到收益选择：可检验联系所需的条件

这是对r5无保证反例的进一步分析，不是新实验协议，不修改当前数值策略，也不声称提出了新的贝叶斯更新数学。r6反馈分叉仍按原固定矩阵执行。

## 一个足够明确的联系

若某诊断只改善Z的预测，而它的Y预测头完全独立，条件证据不能约束收益排序。需要明示同一未知量如何同时影响当前局部响应与未来动作收益。例如，假设固定一个可识别标量θ，并在当前查询x下有

Y = a(x) + μ(x)θ + εY，

Z = b(x) + ν(x)θ + εZ，

其中噪声联合高斯、协方差Σ已知且正定，θ与噪声独立。令c=ΣZY/ΣYY，s²=ΣZZ−ΣZY²/ΣYY，g(x)=ν(x)−cμ(x)，则

Z | Y=y, θ, x ~ N(b(x)+c(y−a(x))+g(x)θ, s²)。

条件Z能辨认θ要求g(x)非零。未来动作x*的期望收益对该参数的敏感度是μ(x*)；若μ(x*)为零，辨认θ不会改善该动作的收益估计。若所有待选动作的μ相同，变化只是共同平移，也不能改善它们的相对排序。

## 在线性高斯假设下能得到什么

设收到Y后θ的后验方差为VY。继续接收同次实验的Z后，方差为

VYZ = 1 / (1/VY + g²/s²)。

对未来动作均值，额外条件信息带来的后验方差下降是

μ(x*)² (VY−VYZ) = μ(x*)² VY² g² / (s² + VY g²)。

该式为标准高斯更新的直接结果，支持“共享参数、非零条件信息、未来收益敏感性”三项要求。它不是当前r4独立回归头已经满足这些要求的证据，也不保证失配模型、有限样本下的实际收益增加。

若使用正确联合模型、最优贝叶斯决策，且新增Z信息不耗额外成本，条件于已知Y的期望最优收益满足信息价值非负（max的凸性）。这不保证每一次实现、启发式贪心查询或带成本情形都改善；本研究不把该标准结论当新的性能保证。

## 与“分离更新”的关键区别

对一个一致的联合概率模型，依次用p(Y)和p(Z|Y)更新，与直接用p(Y,Z)更新完全相同。因此，上述共享参数模型可以说明信息怎样作用于决策，却不能凭分解记账声称优于联合更新。

如果刻意让诊断支持只接受条件因子而排除Y边缘，就是不同的模块化更新假设。它需要具体说明为何Y边缘会误导诊断、哪些共享参数仍允许用Y学习，以及这种隔离会损失哪些有效信息。不能一边忽略Y对诊断的影响，一边引用完整联合贝叶斯更新的最优性作为保证。

## 实际研究准入问题

后续候选必须先给出：θ的业务含义；从合法父状态测量到μ/ν的固定映射；为什么该映射能跨任务适用；g的可辨认条件；源数据拟合与新任务反馈的合法边界；与普通联合结构回归的实质差别。当前生成信号主要是窗级聚合，目标Z却对应预测时域后半段；二者之间的载荷映射不能凭命名自动成立。

在这些事项不明确时，继续调条件分数温度或给Y预测乘可靠性不会补上联系。当前已完成的真实开发结果和r6分叉结果应作为约束，而不是事后挑选映射的训练目标。本文件没有授权新来源完整训练、生成新特征或追加LLM调用。
