# 噪声感知代理的必要性：联合动作池与信息充分性审查

2026-10-14。只读使用已经完整揭示、审计及发布的36组S/W配对结果。本阶段新增完整训练、代理轨迹、优化器更新均为0，累计完整训练409。联合动作池与下述对照在看到结果后定义，全部属于事后必要性分析；旧协议、预测、响应和原推荐评价保持不变。

## 决策：本轮不扩展噪声代理

上一轮支持同μ代理的数值信息缺口，但不足以支持增加噪声模块。本次进一步检查了允许采样与加权共同竞争的自然决策问题：若沿用M1的动作推荐，并在S/W相同预测时固定优先W，当前池距事后最优的平均差距仅0.021000pp、最大任务差距0.063001pp。更复杂的候选预测器在这一评价目标下最多填补该差距。该结论只限当前已知池，不能据此排除其他任务中的噪声价值，也不能把事后优先W改写成已验证部署策略。

因此保留原M1和两种简单实现优先规则作为后续参照；不启动Gaussian噪声模拟、方差迹校正、M2或新增种子/倍率实验。下一步转向审查干预决策空间与合法任务入口，先建立值得预测的新增决策问题，再另冻必要实验。

## 1. 联合池的完整机会空间

原报告分别在S的四动作+PARENT和W的四动作+PARENT中评价M1，六项推荐遗憾为0。新分析的每任务菜单是八个实现明确的动作加一个PARENT；S/W预测相同。先依原规则以三个种子的平均预测选动作，预测改善至少1%才采用，再分别固定优先S或W。两个优先规则均不使用真实子响应挑选实现。

事后oracle在全部八个动作和PARENT中取三种子平均真实收益最大者。它是该池的上界，不是可用方法。评分仍是每任务选择一个共同动作后的三种子平均百分比改善，再对三个任务等权平均。此上界不适用于允许按已知真实种子结果另选动作的新目标；本轮没有将每种子的事后最优冒充可预测收益。

## 2. 仅加二阶噪声统计没有一般充分性

同μ仅约束期望梯度。Adam将随机梯度经过平方、累积、开方及相除；将这些操作施加于均值一般不等于先操作再取均值。完整协方差也没有无条件充分性，方差迹更不能单独决定响应的正负。

一个纯代数反例：独立逐样本标量梯度A取−1/+1各一半；B取−1/2与2，概率分别4/5和1/5。两者均值0、方差1。以256个独立样本取batch均值，两者仍均值0、方差1/256。零Adam状态、偏差校正、epsilon=1e−8及无权重衰减时，首步除以−学习率后的量为`gbar/(|gbar|+epsilon)`。完整二项式求和分别得到0（60位计算残差约1.1e−60）与−0.0498209727937608。

这只否定“一二阶矩相同必然同Adam响应”的一般命题。没有生成传感器记录，没有训练模型，也没有断言上述分布存在于本项目数据。它不否定满足额外条件时的SDE近似，更不证明高阶噪声信息具有可利用的选择价值。二阶/Gaussian代理仍可作为近似假设，但必须独立验误差与成本；不能从已有数值缺口直接推出它会修复本项目。

## 4. 后续可证伪入口

现有证据不支持在该已知池上扩展噪声方法训练。继续主线先完成一份新的决策任务设计，要求：

1. 仍固定DLinear、输入表示与训练语义，优先用户指定的现有数据。先核对合法训练内分区与旧候选覆盖；禁止把旧M/S关闭批次换ID恢复，或扫描旧失败阈值/倍率。
2. 新动作必须对应明确的数据干预问题，以A训练信息定义；不得用已知C子响应挑位置、强度或“有优势”的任务。已接触来源如实标注，不能称未见来源。新的子响应揭示前冻结完整任务/动作/预测/推荐及停止规则。
3. 保留M1和直接短训、无需复杂诊断的简单规则；若菜单含S/W，必须包含两种固定优先对照。先独立计时冻结总成本，记录共同父、统计构建、全部失败与评价成本，不能重调旧预算以抹去失败。
4. 主要判断为相同菜单、成本与信息下的真实推荐收益/遗憾，并报告伤害、弃权、覆盖和全部任务；数值MAE单独报告。不能只因预测更准或某些有害候选差异大就进入方法扩展。
5. 若没有可辨别且有实际意义的新决策问题，保留M1的已知开发结果及噪声边界结论，停止该扩展；不能为维持方法正结论追加模块、任务或种子。

这些是下阶段设计约束，不是已冻结的运行协议；当前没有新方法、训练或测试队列。下一步只进行任务/动作覆盖审查与方案选择，具体候选尚未决定。
