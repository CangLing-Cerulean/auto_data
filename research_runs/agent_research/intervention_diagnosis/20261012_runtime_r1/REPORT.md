# 阶段0真实运行验收

服务器开机后，9项Python单元测试、9个冻结R2检查点的逐元素误差导出，以及两个离线原型的真实历史回放均通过。此前“未运行”状态属于20261012_phase0本地交付；本次验收另存，不改写旧协议或旧结果。

每个模型导出300,535个开发窗口×8步×15通道的float32有符号误差，9个张量的SHA256、有限性和总体NMSE全部通过复核。保存源行映射、目标起点、传感器顺序和预测步长。6组父子比较同时输出整体、登记目标、精确元素补集的NMSE/NMAE/偏差及增量；54条长表记录的来源与定义见response_long.csv。

登记目标保持high_input_variation×TP2/H1/DV_eletric×全部8步，共521,136个元素。整体36,064,200个元素，补集35,543,064个元素；三者的加权增量一致性通过。补集包含目标窗口中的其他通道。

三个种子均值之比：历史全正号父配方相对本轮B0，整体NMSE改善约4.31%、目标改善约14.71%；新增符号翻转相对父配方整体退化0.3842%、目标退化13.1094%、补集退化约0.22%。这是旧R2证据的更细粒度重建，不是新增处理发现，不替代原冻结评分。

两个原型收到相同事实/历史/工具，公共信息哈希一致。在三个符号翻转回放中，full均返回retain_parent与retrospective_only，未把已见结果补写成事前支持。此项是确定性接口回归，没有调用新的LLM，不代表强提示词与full的方法效果比较。
