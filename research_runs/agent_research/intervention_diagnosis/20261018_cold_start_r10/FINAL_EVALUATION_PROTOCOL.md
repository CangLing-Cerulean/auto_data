# 冷启动探索后的封存D评价

本协议在任何D测量值读取之前固定。D仅为同一Electricity来源的后续时间段，不称独立来源迁移。两组8次探索结束、最终推荐封存且开发结果验收PASS后，才形成包含源码、推荐、验收和时间索引hash的final_evaluation_lock，发布并核对GitHub后解析D。

读取已登记D行87456:90336，共2880行、370通道；只使用原A的float64均值/标准差标准化为float32。不得因D分布修改归一化参数、删除通道、窗口或重训模型。32→8、stride1，2841个完整D窗口全部评价；保留原始零值。

模型仅为三个seed的共同父与两组各自最终推荐的B-best checkpoint，去重后最多9个模型。没有新训练、LLM调用、备选方案扫描或D反馈回流。若两组推荐相同，只进行必要的去重推理，结果仍分别报告。父推荐的配对改善按0计算。

逐seed报告全D MSE、MAE、残差hash及相对父改善，再报告三seed算术均值，以及SEPARATE−STRONG的配对改善差。三seed是一个任务中的重复，不作为三个独立数据来源；不给不受支持的跨任务显著性结论。C是探索开发结果，D是已固定推荐的时间外推评价，两者分别报告。

每模型固定首/中/末三个输入窗口另做由操作数和运算次数导出的float32绝对舍入界核验，采用已记录coldstart_roundoff.py；此为数值工程检查，不改变D的全窗口指标或原开发验收的固定容差记录。任一真实执行或核验失败保留原状态，不根据D改模型/配方后重报成功。

入口coldstart_final_evaluation.py的prepare只在发布锁通过后解封D；evaluate只做冻结模型推理。源码当前准备不等于D已解封，最终运行必须另生成与发布final_evaluation_lock。
