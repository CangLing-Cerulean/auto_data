# 冷启动结果整理与事后误差分解

本文件形成于两组第三轮附近，已经看到父模型C的MSE明显大于B及早期配方收益接近零。因此下述分解明确属于事后描述，不是事前科学假设或新的采用指标。A统计中34个通道标准差为零，且均全零；这些通道自数据准备时即全部保留。

完整两组8轮结束后，manage_coldstart_audit.py将冻结的审计源码及本轮完整决策记录部署到原实验目录。审计使用独立普通文件记录stdout、stderr和退出状态；不重启训练、不调用LLM。审计源码、原容差与原协议保持。任何失败保存原输出，不把脚本部署成功当作结果通过。

开发审计通过后，report_coldstart_trial.py按所有8次尝试汇总节点2/4/8推荐、全部有效和无效尝试、有害响应、Y/Z预测绝对误差、Y边际与Z给定Y的95%预测区间覆盖、实际和逻辑训练成本及LLM成本。逻辑分组成本不含监督开销；总实验墙钟包含串行调度和网络等待。环境安装的完整耗时未知，记null而非零；数据注册和安装不包含在该实验墙钟中。

同样在全部探索结束且开发审计通过后，coldstart_metric_decomposition.py重新计算每个已完成模型的完整C残差，并核对原C指标。仅依据已保存的A原始标准差是否为零，将全部370通道分成两个互补组，报告每组MSE、对原全局MSE的加法贡献和占比、逐通道MSE，以及A常量通道季节/趋势权重是否与初始化逐位相同、偏置幅值。不得用该分组改变原评分、删除通道、重新推荐、给实验Agent补充反馈或追加训练；它不能单独建立因果解释或一般收益上界。

本阶段源码准备未访问D。D仍须遵守FINAL_EVALUATION_PROTOCOL和后续独立发布锁。两组的全部探索结果、失败、条件证据、原数值检查失败和补充检查均保留到最终报告与归档。
