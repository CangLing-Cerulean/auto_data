# M1与N1 N2算法规范

本规范保留固定DLinear训练问题。M1是当前主方法，N1与N2是可选扩展。以下定义分别标明真实训练、数学代理和事后评价，算法参数及实验规模以[实验协议](PROTOCOL.md)和[参数登记](protocol.json)为准。

## 1 数据操作与真实训练

令一个窗口为x_i∈R^(32×8)、y_i∈R^(8×8)。保留原双分支DLinear、每通道独立参数、移动平均核25、复制填充和两个偏置；每通道每输出的原坐标维度为66，总参数4224。不得改用合并后的仿射矩阵训练。

完整操作表示为(T_u, π_u, w_u)。本版固定T_u(x)=x，π_u(i)=1/n，只调整训练损失权重。A内308个完整周期按原周期号排序，连续每77周期一组，共G=4组；每周期21个合法窗口，每组1617窗。周期号仅作稳定分组，不解释为真实时间或物理工况。

设g(i)为组号，q_g=n_g/n=1/4：

    w_i(u) = 1 + u_g(i)
    qᵀu = 0
    |u_g| ≤ ρ = 0.20

父操作u=0。候选仍均匀有放回抽样，父子使用同初始化、同seed+1000随机流及相同实际窗口索引。权重乘入平方误差后对固定B×C×H元素取均值：

    J_batch(θ,u) = mean[(1+u_g(i)) (f_θ(x_i)-y_i)²]

不除以批内权重和，不改变标签、标准化、评价分母、样本呈现数或学习率。标准化只使用原A已拟合参数；B/C全部合法窗口均参与评价。上式是理想候选空间；转float32后保存精确权重字节，实际向量u_eff=w_float32−1满足|qᵀu_eff|≤1e-7、|u_eff|∞≤ρ+1e-7。这个容差仅容纳数值表示误差，不改变科学幅度或允许再次归一化。超界停止，不裁剪。M1/SOURCE矩、真实训练和所有报告均使用实际权重，不把其微小质量偏差改记为零。

训练固定Adam，lr=0.001，betas=(0.9,0.999)，eps=1e-8，weight_decay=0，batch=256，3000步；执行前须与旧父优化器状态逐项核对。原配置若有任何差异则停止，不能用本段数值覆盖父协议。初始化及K={500,1000,1500,2000,2500,3000}保存模型、优化器及随机状态。

## 2 评价目标与信息权限

每个种子s独立按B损失严格最小选择检查点k*_s(u)，并列取最早；在C计算F_s(u)。NMSE和NMAE均沿冻结评价实现。定义：

    Gain_s(u) = 100 [1 − F_s(u)/F_s(0)]
    Gain(u) = mean_s Gain_s(u)

同一任务必须对所有种子使用同一组u，不对种子分别寻优。父基准F_s(0)>0；非正或非有限值视为输入错误。

| 信息 | 允许用途 |
|---|---|
| A的窗口、标签、周期和原标准化 | 拟合、分组、矩计算、训练 |
| B的标签和父残差 | 原检查点选择与代理分支检查 |
| C的标签和父残差 | 开发阶段候选评分；N2权重提案 |
| 完整候选训练前的M1或N1输出 | 预测及推荐；它们是估计值 |
| 完整子模型及其C结果 | 预测锁后的真值、误差、机制和选择审计 |
| 旧D、基础validation/test | 本版不读取；已揭示D不重称独立未见 |

C被用于N2优化，因此其结果属于开发收益。所有算法均不能从完整子响应、最佳真实动作或事后误差中生成本轮事前候选。

纯训练加权不改变推理输入，固定父作用d_u=0，全部处理响应来自训练适应q_u。真实q_u和真实代理误差在完整子产生前不可观测；可计算的是其预测及父参照。

## 3 M1主算法

令每通道特征φ_i=[seasonal(x_i),1,trend(x_i),1]，参数Θ_c为66×8。μ_i=(1/n)w_i。由全A计算：

    G_u,c = Σ_i μ_i φ_i φ_iᵀ
    R_u,c = Σ_i μ_i φ_i y_iᵀ
    g_u,c(Θ_c) = 2/(C H) (G_u,c Θ_c − R_u,c)

不在G/R中另行归一化。用上述期望梯度、原参数布局及原Adam运行3000步的父、子代理，各自维护合法优化器状态。真实父在每个K的参数已知，构造：

    Θ_hat_u,k = Θ_real_0,k + Θ_proxy_u,k − Θ_proxy_0,k

只组合模型参数，不组合Adam二阶矩或继续从组合状态训练。在B选代理检查点，再在C预测Gain。RAW使用Θ_proxy_u,k，其他评价规则相同。

M1的期望梯度精确不意味着随机Adam轨迹精确。其关键机制是父子代理误差在预测空间中部分抵消；该机制以及真实Gain预测误差都须用完整子审计。

M1主算法伪代码：

    验证输入与协议锁
    读取真实父和匹配代理父
    对共同菜单每一u：
        从A构造μ与G/R
        从原初始化运行子代理，保存全部K
        对每个K组成M1参数，分别评价B与C
        M1与RAW各自只按B选点
        输出三种子预测、均值和完整曲线
    按同一1%采用门槛锁定推荐
    与SOURCE和SHORT共同冻结预测及成本
    通过协议门槛后生成完整子标签

SOURCE沿用已验收的DLinear公式适配、500步分段及原P定义，数据扰动改为μ_u−μ_0；不得调整近似参数。它是固定实现基线，不称作者Adam实现完全复现。

## 4 N1可选局部响应

N1对固定批次、连续损失权重求导。使用三个质量守恒方向组成正交基Z：

    z1 = (1,−1,0,0)/sqrt(2)
    z2 = (1,1,−2,0)/sqrt(6)
    z3 = (1,1,1,−3)/sqrt(12)
    u=Zv，qᵀZ=0，ZᵀZ=I

为明确计算float32权重的微小公共质量偏差，再加入数值补偿方向z4=(1,1,1,1)/2。令W=[Z,z4]，WᵀW=I。优化仍只有三个合法变量v，理想系数a=(v,0)；z4不扩大科学操作空间。

传播参数与Adam状态对a的导数S_t、M_t、V_t，形状均为p×4，初始均为0。实际u_eff唯一分解为a_eff=Wᵀu_eff，预测时四列全部参与，不能将实际向量投影回零质量空间而丢掉舍入影响。沿真实父批次梯度g_t：

    H_t = ∂g_t/∂θ
    C_t = ∂g_t/∂a | 固定θ
    C_t[:,j] = mean_batch [W[g(i),j] ∇θ ℓ_i]
    Gdot_t = H_t S_t + C_t
    M_(t+1) = β1 M_t + (1−β1) Gdot_t
    V_(t+1) = β2 V_t + 2(1−β2) diag(g_t) Gdot_t

H_t S_t用批次二次矩或Hessian向量积实现，不构造p×p稠密矩阵。M、V的偏差校正沿父状态的真实step。令mbar、vbar、Mbar、Vbar为校正量，d=sqrt(vbar)+eps：

    S_(t+1) = S_t − η [
        diag(1/d) Mbar
        − diag(mbar/(2 sqrt(vbar) d²)) Vbar
    ]

此表达适用于vbar>0的分量。对真实父该参数此前梯度全为0的零二阶矩分量，父mbar=0，联合更新映射的一阶导数使用−η Mbar/eps；须有独立标量/JVP核验。其他异常零值、非有限值或状态不一致直接报错，不通过增加平滑项修改Adam。

父模型更新仍调用冻结实现，逐K核对真实父状态。切线量可用float64计算，但其含义是实数更新映射在已实现父路径上的敏感性近似，不宣称对IEEE浮点程序逐位求导。分别报告float64代数核验和float32完整训练有限差分的一致性。

固定K、分区D∈{B,C}：

    e_D,s,k = f_θ0,s,k(X_D) − Y_D
    J_D,s,k = Φ_D S_s,k
    r_D,s,k = Q_D^(1/2) e_D,s,k
    K_all_D,s,k = Q_D^(1/2) J_D,s,k
    K_D,s,k = K_all_D,s,k[:,0:3]
    L_hat_D,s,k(v) = ||r_D,s,k + K_D,s,k v||²
    L_hat_actual_D,s,k(u_eff) = ||r_D,s,k + K_all_D,s,k Wᵀu_eff||²

纯加权没有输入直接导数。Q固定编码原评价；NMAE使用同一评价尺度的e、J和原绝对误差平均权重ω，不能把NMSE残差权重直接当作NMAE权重。

实施时可逐块累计四列K_all的交叉矩和残差内积，避免保存所有窗口的稠密响应。NMAE约束仍需可逐块重建e、J。每个检查点保存S/M/V、B/C充分统计、状态绑定及完整可重建信息。N2优化用前三列，实际权重预测及审计用四列。

## 5 N2可选求解器

N2只产生提案，不改变DLinear训练正则。对种子s，令k_s为真实父的B最佳检查点，r_s和K_s取C上该点，F_s(0)=||r_s||²。三种子共求一个v：

    min_v  mean_s [||r_s+K_s v||² / F_s(0)]
           + λ vᵀ ZᵀD_q Z v
    λ=0.01，D_q=diag(q)

λ是本版固定的决策收缩常量，不按开发效果搜索。基本约束为|Zv|∞≤0.20与ESS≥0.98n：

    Σ_g q_g [1+(Zv)_g]² ≤ 1/0.98

对每个种子，C的整体预测NMAE≤1.01×父NMAE，每个输出通道的预测NMSE≤1.05×父通道NMSE。这些是代理护栏，真实标签后还须单独核验；不能保证真实无害。零基准以绝对0处理，不人为加分母。

### 5.1 保留原检查点选择

不同检查点的二次损失之差一般非凸。本版采用固定父分支的保守凸约束，不把多分支选择隐藏在一个凸优化声明中。

对种子s与竞争检查点j≠k_s，在B上定义：

    gap_sj = ||r_B,s,j||² − ||r_B,s,k_s||²
    a_sj = K_B,s,k_sᵀ r_B,s,k_s − K_B,s,jᵀ r_B,s,j

若任一gap_sj/max(L_B,s,k_s,1e-12)≤1e-8，N2本任务返回PARENT并标为分支不支持，任务仍计入覆盖分母。否则约束：

    2 a_sjᵀv + ||K_B,s,k_s v||² ≤ gap_sj/2

因为精确代理损失差还含−||K_B,s,j v||²，上式足以保证在线性残差代理内父分支仍领先至少gap/2。它不保证真实子不切换。

解出v并转换实际float32权重后，用四列响应及a_eff重新计算所有检查点的代理B损失，执行原最早最小选择器并核对仍选择k_s；上述保守约束也以四列系数重新核验。真实子训练始终按原B选择，发生真实切换时照实评分、记录代理失配，不改成父分支或last分数。

### 5.2 数值求解与输出

使用CVXPY表达凸二次/SOC及绝对值约束，由Clarabel求解。具体依赖版本在实现冻结时锁定；不能臆填尚未安装的版本。目标因λ>0、q_g>0及Z满列秩而严格凸。

调用前验证is_dcp()。只接受optimal状态；optimal_inaccurate、超时、不可行或非有限解均保留失败并停止，不调用另一求解器寻找有利结果。归一化约束最大正违反≤1e-7，求解器gap/feasibility目标1e-8。B分支约束除以max(父B损失,1e-12)，C的NMSE/NMAE约束除以max(对应父指标,1e-12)，质量、半径和ESS采用已定义的无量纲值。转换实际float32权重后，按第1节的质量/半径容差及四列实际预测再次核验；实际ESS/n用(qᵀw)²/Σ_g q_g w_g²计算，不能继续假设舍入后总质量精确为1。超界不修补。

保存原始提案、实际权重、所有预测和约束残差。三种子平均预测Gain≥1%且预测NMAE护栏通过才推荐提案，否则推荐PARENT；仍保留未采用提案用于预登记的预测验证。

### 5.3 一阶目标消融

LINEAR使用同一真实路径导数、同一可行集和λ，仅将C目标中的||K_s v||²项删除：

    min_v mean_s [2 r_sᵀK_s v/F_s(0)] + λ vᵀZᵀD_qZv

它保留护栏中的曲率信息，因此只检验目标中的二次响应项，而非“使用全部响应信息”的整体因果贡献。该比较共享N1计算，但各方法独立成本账本都支付完整N1成本，实际研究执行只计一次。不能把LINEAR称为Ren等人算法的复现。

## 6 接口与失败语义

建议实现以下局部模块，复用旧代码只读接口，不改写旧runner：

| 模块 | 输入 | 输出 |
|---|---|---|
| task_builder | 基础train身份、旧ABC与父资产、固定分组规则 | 行映射、组号、标准化绑定、input_lock |
| moment_predictor | 任务、固定u菜单、父与代理父 | M1/RAW全部K及推荐 |
| parent_replay | 初始状态、固定窗口与随机流 | 可核对的父轨迹、前缀计时 |
| tangent_replay | 同一父路径、W及其前三列Z、原优化器 | S/M/V、B/C响应、数值诊断 |
| constrained_proposal | 三种子响应和固定约束 | FULL/LINEAR各一个共同u或明确状态 |
| comparison_runner | 冻结菜单、校准步数、预测锁 | SOURCE/SHORT预测及真实完整标签 |
| independent_auditor | 基础train、全部冻结与原始资产 | 状态、指标、成本、身份与结论核验 |

状态区分工程失败、分支不支持、无合格推荐、成本失败、科学门槛失败和完成。PARENT是合法决策；工具错误不能伪装成无收益，停止也不能丢弃已完成结果。

## 7 理论与相关工作边界

有限训练链式求导、控制变量式差分、凸二次代理和信赖域思想均有既有基础。本版没有提出无偏性、跨来源误差界或统计置信保证。N2的凸性仅属于规定的局部代理；M1是否有价值及N2是否改进真实选择由实验判断。

- [Maclaurin等 2015](https://proceedings.mlr.press/v37/maclaurin15.html)：通过训练过程计算验证目标的超参数梯度。
- [Ren等 2018](https://proceedings.mlr.press/v80/ren18a.html)：利用验证信息进行样本重加权；后续论文比较需实现适当强基线，不能只引用名称。
- [DeltaGrad](https://proceedings.mlr.press/v119/wu20b.html)：利用缓存训练信息处理数据变化；不等同于本M1差分估计器。
- [CVXPY DCP规则](https://www.cvxpy.org/tutorial/dcp/index.html)与[求解器文档](https://www.cvxpy.org/tutorial/solvers/)：支持本版凸代理的实现选择，不支持真实收益保证。

以上为定向来源核对，不是完整创新性检索。已有M1局部成果、SOURCE适配范围和停止结论见[既有主张边界](../20261014_file_transfer_r1/CLAIM_CLOSURE.md)。
