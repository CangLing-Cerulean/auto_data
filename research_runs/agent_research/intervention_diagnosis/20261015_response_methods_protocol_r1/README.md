## 本版决定

M1继续采用已验收的原参数坐标、全量矩、原Adam和父子差分校正，不在这个版本同时修改其估计器。下一轮提出一个新的四组连续损失加权开发问题，先检验完整共同动作池中的响应和选择价值。四组按训练周期号定义，所有操作均保留训练窗口及原采样分布。

该问题使用已有Hydraulic G1至G3的A/B/C、父模型和三个种子，属于已接触来源上的新操作开发检验。这样能复用已验收资产，并把采样概率变化与损失权重变化分开。它不承担跨来源确认；若开发通过，独立确认仍需另行登记。此任务选择与新数值常量均为本设计的明确提案，未被描述为用户逐项指定或实测最优。

旧M/S、FTR1批次继续关闭；它们的同推荐、预算失败及未知标签保持。新的四组权重向量须与历史已运行权重做身份比对，精确重复资产只读复用，不换ID重复训练。旧双组动作、删除强度或失败阈值不再扫描。

N1与N2是一条单独登记的可选扩展：N1计算固定随机批次下的局部训练响应；N2据此提出一套跨种子共用的连续权重。它们不替换M1，也不因M1某项失败而自动启动。N3、N4、N5保留概念入口，本版没有这些模块的运行队列。

## 设计与执行的边界

本版可以直接用于实现和代码审查。实际运行前仍须生成输入资产锁、代码与环境锁、容量验收和成本校准收据；这些值只能通过实施获得，不能预填。参数登记中的执行标志为false。用户本轮要求整理协议，没有要求立即启动服务器实验。

每阶段先冻结再计算；所有结果、失败及成本单独保存。科学阶段仍分别判定数值可信、响应精度、推荐增量和成本，不能把代码或审计通过写成方法有效。当前没有新的效果预测、独立来源成果或最终测试结果。
