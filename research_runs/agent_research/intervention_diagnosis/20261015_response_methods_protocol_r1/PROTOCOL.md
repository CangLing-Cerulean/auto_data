# M1持续研究及N1 N2分阶段实验协议

2026-10-15。状态为设计已定义、执行未激活。用户要求整理可实施的算法和实验协议，并明确M1继续作为研究主线。本文不启动训练，不修改旧协议和结果。机器参数见[protocol.json](protocol.json)，数学及接口见[ALGORITHM.md](ALGORITHM.md)。

## 1 研究问题与成功口径

M1主问题：固定DLinear、Adam、训练长度和推理输入后，M1能否在四组训练窗口的有限损失加权问题上，以不高于登记短训对照的选择成本，更准确估计完整重训响应，并产生更好的推荐？

本轮只检验一个已接触Hydraulic开发来源。三个任务、三个种子及24个任务动作不是24个独立来源。当前数据支持开发检验，跨来源稳定性与最终测试不在本次可宣称范围。

四组加权是新的操作问题，M1估计器不变。任务、分组、半径、共同菜单和评价在任何新候选完整训练前锁定。不能根据本轮响应缩小半径、合并组、换任务或增加候选。主线停止一批实验不等于永久放弃M1；任何新的估计器修改须另给可检验理由和独立版本。

N1与N2另问：真实有限路径的局部响应是否可计算且在规定邻域内可信；据此直接求权重，是否优于简单的一阶目标及已有M1选择？它们没有自动执行权，不与M1合并成功率。

## 2 固定任务与复用资产

使用既有Hydraulic G1/G2/G3的A/B/C。周期范围均为半开区间，沿原零起始周期编号：

| 任务 | A周期 | B周期 | C周期 |
|---|---|---|---|
| G1 | [0,308) | [308,385) | [385,462) |
| G2 | [514,822) | [822,899) | [899,976) |
| G3 | [1028,1336) | [1336,1413) | [1413,1490) |

每任务A为308周期、6468窗口；B/C各77周期、1617窗口。所有窗口来自原基础train，不跨周期或原间断；输入32、输出8、8通道。若实际重建计数与原准备资产不一致，则停止，不补造窗口。

种子固定2026101701、2026101702、2026101703。复用已验收的9个真实父、9个代理父、原A标准化和源行映射。不得直接信任旧临时路径：运行前从已核验归档按成员哈希定位，在新目录读取副本，旧资产只读。

只按原A周期号排序，连续每77周期组成一组，得到四组各1617窗。分组不使用B/C残差、旧子响应或模型重要性。这是稳定周期组，不称已识别物理工况。

原文件、规范化、窗口、父状态、代理父状态和原源码组成input_lock.json。逐文件路径、大小及SHA256必须完整；本设计的input_manifest只锁依据文档，不替代运行资产锁。

## 3 M1共同动作与比较方法

令d_g的第g个分量为1，其余三个为−1/3。依次登记八项：

    G0_UP, G0_DOWN, G1_UP, G1_DOWN,
    G2_UP, G2_DOWN, G3_UP, G3_DOWN
    u(Gg_UP)=+0.20 d_g
    u(Gg_DOWN)=−0.20 d_g

均满足qᵀu=0、所有样本保留、固定均匀采样。选定组权重为1.20或0.80，其余组分别为1−0.20/3或1+0.20/3。每任务8动作、3种子，共72项完整候选。PARENT是额外零干预参照。

这是单一预设幅度、四个组方向的对称菜单；四方向之和为零，合法自由度为3。0.20是温和权重扰动的设计常量，没有经过收益调参；本轮不搜索更优幅度。实际执行float32权重及其质量偏差在准备阶段锁定，质量和半径的表示容差均为1e-7。

| 方法 | 计算与信息 |
|---|---|
| M1 | 固定成对全量矩代理，全部K按B选/C评 |
| RAW | 同一子代理，不作真实父差分校正 |
| SOURCE | 原已验收公式适配，输入为同一加权目标的概率乘权重质量差 |
| SHORT | 从共同原初始化按实际候选权重真实短训，统一固定步数 |
| PARENT | 全部保留、原真实父 |

每种预测方法分别对同一动作的三个种子相对NMSE改善求均值，选择最大值；最大值≥1%才推荐，否则PARENT。并列按上述菜单顺序。不给不同方法不同动作，也不按种子分别选动作。NMAE及各通道指标保留并在真实标签后验收。

M1/RAW/SOURCE不能读取SHORT训练状态，SHORT不能读取完整子标签。方法可以共享原始合法输入，但各自需要的矩构建、评价和写盘须计入各自成本，不免费借用其他方法独有中间量。

## 4 成本校准与有限预算

先在新诊断目录独立重放原9个真实父和9个代理父，核对状态并计当前环境下的初始化、训练、逐K B/C评价及必要写盘/哈希成本。它们属于既有轨迹重放，单独记更新步数与实际开销，不新增科学父ID或累计完整训练数。任何不一致停止，不能覆盖旧模型。

对任务t的三个种子，令P_t为代理父端到端耗时最大值，E_t为M1恒等操作六检查点评价耗时最大值。每候选校准量：

    c_t = (1+1/8) P_t + E_t

SHORT步数从{500,1000,1500,2000,2500}中选择最小k，使三个真实父到k的端到端前缀计时最小值≥1.25 c_t。没有满足者则停止该批，其他任务不得继续作为缩小后的成功样本。校准选择仅依据耗时，不依据子效果；校准收据先发布再运行候选。

每任务每种子核对：

    M1选择成本 = 代理父成本 + 8个代理子成本 + M1评价成本
    SHORT选择成本 = 8个短训端到端成本
    M1选择成本 ≤ SHORT选择成本

代理子与RAW共享实际执行时只跑一次，但分别记各自方法账本。共同真实父与任务准备另列。报告已有父条件的选择成本，以及加入共同父和准备的冷启动分摊成本；分摊不称各方法独立冷启动实测。

完整标签后另检查M1选择成本≤本任务种子全部8个完整子实际端到端成本的50%。原始重放、数值诊断、失败、审计、传输分别记账，未知时间保留null。该设计没有货币额度或全研究时间重置；运行数量有明确上限。

8. 前述门槛均通过后，运行全部72项完整子，包括被各方法拒绝的动作；不只训练推荐项。

## 6 M1科学验收

主MAE：先对每任务动作的三种子预测和真值各自求均值，再求绝对误差；每任务8格均值后对三任务等权平均。单位是改善百分点，不是原NMSE绝对值。同时给逐种子误差、每任务误差、全部24格及不稳定格。

| 条件 | 本版固定要求 |
|---|---|
| 精度相对幅度 | M1 MAE≤0.8×min(RAW,SOURCE,SHORT的MAE) |
| 精度绝对幅度 | 相对同一个最佳动态精度基线至少降低0.05个百分点 |
| 任务覆盖 | 至少2/3任务MAE不高于上述同一个最佳动态基线 |
| 推荐增量 | 三任务平均真实推荐Gain≥最佳RAW/SOURCE/SHORT/PARENT策略＋0.10个百分点 |
| 伤害限制 | 每任务推荐平均Gain≥−0.25%；每种子推荐NMAE退化≤1% |
| 成本 | 第4节的SHORT及完整穷举成本条件全部通过 |
| 完整性 | 输入、冻结顺序、状态、指标、全部动作和成本独立核对通过 |

响应类别沿用>0.25%改善、<−0.25%伤害、其余基本不变；跨种子类别不一致另标不稳定。采用资格仍是三种子平均NMSE改善≥1%，并核对原NMAE条件。

报告包含父的原始oracle、满足采用条件的oracle、各策略遗憾、伤害推荐、弃权和覆盖。种子重复不能增加独立任务数。全部条件通过只支持这个开发批次的局部价值；任何失败保留该项失败，不降低门槛。

## 7 N1数值工程扩展

N1不自动启动。其实施须单独锁定代码、同一组定义与状态范围。以本版9个父为输入，在真实父批次上增加三个合法方向和一个公共质量舍入补偿方向的切线传播；优化自由度仍为3。原校准已经有同环境的普通父重放时直接复用，不重复付一次“新父”。

先做以下无新增科学模型检查：

- 原坐标特征、梯度因子与原自动微分一致；加权loss采用固定分母。
- float64小矩阵和真实批次的一步/多步JVP对照；普通、零二阶矩及冗余坐标均覆盖。相对容差1e-9、绝对容差1e-11用于float64代数测试，不能套到float32真实轨迹。
- 9个零干预重放逐K核对模型、Adam、随机状态；规范要求逐位一致，环境变化导致不一致则停止并解释，不当作近似成功。
- 9个父的全部六检查点保存S/M/V与B/C响应；不从稀疏检查点插值补齐路径。

完整有限差分只在预先固定的G1、种子2026101701进行。W的四个方向，每方向h∈{1/64,1/128}、正负两侧，共16条3000步轨迹。第四方向仅核验公共权重缩放的数值补偿，不作为合法质量守恒的科学候选；准备器只为这四个登记的第四方向诊断ID允许已知均值1±h/2，其余科学输入仍执行质量守恒检查。每条都是新的完整诊断训练，计入累计完整训练，不能当作免费审计重放。它们使用固定批次，在全部六个K及B/C检验中心差分，不通过best选点比较导数。

对每个方向、h、K、分区定义：

    FD = [r(+h w_j)−r(−h w_j)]/(2h)
    relative_error = ||FD−K_direction||
        / max(||FD||, ||K_direction||, 1e-6 ||r_parent||)

两个h的全部比较均要求relative_error≤0.02；两个FD之间用同样归一化的差异也≤0.02。若梯度信号低于分母下限，标记低信号并保留绝对误差，不据此宣称高相对精度。16条是固定数值诊断菜单，不选择其中的有利h作为处理候选。实际差分使用各侧保存的float32权重；同时用Wᵀ(u_eff_plus−u_eff_minus)/(2h)确定实际差分方向，不能忽略舍入导致的其他方向分量。

2%为本版工程一致性界，不是统计置信度；单任务完整差分覆盖不能扩称所有来源的导数均已证实。运行前必须锁定该界，失败后不在本批放宽或新增h。诊断的完整子结果仅供核验，不能进入N2输入或帮助调整ρ、λ、分组。

## 8 N2提案实验与M1的关系

本扩展的收益比较以前述M1完整标签已获得独立验收为前置。若M1在标签前停止，本设计不通过N2重新开启那些关闭标签；此时N2只保留算法规范，新的科学运行必须另行登记。M1若完成标签但某科学指标失败，其失败保留，N2只能作为另一个方法问题评价。

N1工程通过且扩展单独激活后，每任务输出FULL和LINEAR各一套共同权重，按算法规范分别保存原始提案及推荐。均从相同父、A/B/C获得信息，不读取本轮M1完整子、FD原始子残差或任何oracle。实现、信息输入清单及常量须在FD标签出现前锁定，执行者只向提案模块提供规定父资产。

每任务3种子×2提案，最多18条新完整训练。PARENT和实际float32权重完全相同的提案按规范哈希复用既有资产；不以近似相等合并。被预测拒绝但非零的原始提案仍在该18项范围内完整验证，以免只报告成功建议。

先保存并发布全部提案、所有K预测、实际执行权重、约束残差、成本及推荐，再揭示这18项真实结果。真实训练仍按原B选best；实际检查点切换不删除。

验收分别记录：

1. FULL在自己三项提案上的三种子均值Gain预测MAE≤0.25个百分点；至少2/3任务误差≤0.25个百分点。
2. FULL三任务推荐均值至少比LINEAR和已冻结M1/RAW/SOURCE/SHORT/PARENT中的最佳策略多0.10个百分点；任一任务平均Gain≥−0.25%，每种子推荐NMAE退化≤1%，每种子推荐的每通道真实NMSE退化≤5%。
3. FULL的每任务三种子总选择成本不超过M1在该任务已登记的实际总选择成本；成本含必要父重放、切线传播、B/C统计、求解和必要写盘。超过即停止新增N2完整标签，不加M1菜单来提高上限。
4. 覆盖分母固定三任务；分支不支持、无合格提案及PARENT均保留。记录原始提案的真实护栏违反、检查点切换和拒绝是否正确。

这些是本设计新提出的扩展判据，不追写为旧M1判据。FULL与LINEAR共用N1仅在实际执行账本节省一次，方法账本各自完整支付。数值FD成本计入开发总成本，不能从实际研究消耗中消失。

N2与M1使用同一合法权重空间，但M1本轮只搜索八个登记点，N2连续构造提案。因此相对M1的收益差属于整套构造和选择流程，不能单独归因为响应更准确。FULL与LINEAR限定控制的是目标二次项。该原型仍不足以宣布优于所有已有重加权算法；正式论文需要进一步的多步重权强基线与独立确认。

不在本轮根据预测/真实收益比调整半径、重求提案或迭代接受新父。ρ=Δ真实/Δ预测只作事后诊断，分母非正时不计算。
