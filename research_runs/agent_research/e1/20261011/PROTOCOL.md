# E1 固定预测协议下的数据干预响应差异与条件化选择

日期：2026-10-11。状态：协议化草案，未冻结、不可启动。当前授权范围为整理 MetroPT3 开发证据，新来源留待补充。本目录提供协议和记录契约，不新增训练、API 调用、测试评价或历史结果重标。

研究顺序为条件差异、探针信息、经验迁移。E1 先确认处理响应是否依赖任务条件，以及干预前状态能解释多少差异。E2 再评价探针反馈，E3 再评价适用边界迁移。本协议不替代正在接续的 [signal v2](../../phase4/20261010_signal_v2/protocol.json)，不改变其评分、分母、运行身份或冻结经验库。

## 当前证据范围

当前基础数据仍为 metropt3_v1，文件身份和分区以 manifest 为准。禁止覆盖、重新划分基础数据，禁止新增合成传感器观测。已使用的开发区间继续标记为开发；更换训练种子不恢复其隐藏性。旧测试已评价，不进入候选选择、经验输入或新的隐藏审计。

当前只整理可比性和出处。尚未生成逐次响应数据，不将模板或缺失记录计为实验。历史数据处理结果、冻结 MLP、signal v2 和旧失败记录保持原身份。输入变换已有符合项目预登记标准的受控开发成果；它支持当前协议下的合法改进空间，不直接支持 Agent 自主发现或跨来源泛化。

## 任务单位

一个 task 是具有固定训练范围、开发范围、目标和评价协议的完整预测决策问题，登记 task_id、source_group_id、dataset_snapshot_id、training_interval、development_interval、audit_interval、target_definition、forecast_protocol_id、evaluation_protocol_id。

source_group_id 按共享来源、重叠序列及衍生关系分组。传感器、工况和变化率切片仅是任务内诊断范围；不因局部误差不同新增独立任务。训练重复用于描述随机性，评价时间或来源隔离用于评价外推，两者分别登记。

MetroPT3 历史内部原点可作为不同开发条件的候选任务定义，但须核对原协议、窗口和区间后独立登记；本草案不自动把它们列为完整任务。同源任务全部属于同一外层来源组。本阶段 audit_interval 为 null，audit_status 为 unavailable，不得借用旧测试或已使用开发段填充。正式 E1 评价需另行登记任务集合；单一来源阶段只报告开发分析。

任务来源、区间及分组不能依据候选效果反向挑选。可另设条件辨别子集，但须记录选择规则，并同时保留未经效果筛选的任务集合。

## 固定预测与数据边界

沿用原 DLinear individual，15 通道，32 条历史预测 8 条未来，最大相邻间断 30 秒，窗口不得跨分区；步数不解释为固定秒数。固定 3000 更新、batch 256、Adam、学习率 0.001、weight decay 0、分解核 25。标准化仅在该任务训练区间拟合，评价尺度随后固定；保持原目标和所有合法评价窗口。

每 500 步按开发 NMSE 选择检查点，保留第 3000 步检查点。E1 主检查点规则保持一致；共同步数审计另列。不同历史预测协议、训练剂量或评价范围不混排绝对指标。新任务维度或时间约定不兼容时另行登记，不能静默适配。

样本分布干预与输入表示干预分层报告。表示处理记录来源通道、可利用信息、训练/推理应用方式及消融，不增加可训练模块。筛选和变换拟合仅使用训练资产；开发误差作为策略可见反馈，不将开发真值当预处理拟合数据。执行代码、训练和研究计算继续在专用 4090 服务器运行，本地仅编辑、整理和审阅。

## 动作规则与实例

action_rule_id 指定算子、参数规则、目标样本定义、拟合范围和操作阶段；action_instance_id 绑定具体任务、实际参数、窗口/源行映射、掩码或权重、实现及制品哈希。实例一经用于响应比较即不可原位改写。

| 规则族 | 登记内容 | 必须检查 |
|---|---|---|
| 不处理 | 全部合法窗口、均匀采样 | 共同评价范围、配对基线身份 |
| 增权与降权 | 同一 T 定义窗口组、具体幅度 | 全训练窗口平均权重归一到 1、非负有限值、有效样本量 |
| 采样调整 | 概率、是否逆概率校正、损失目标 | 概率和为 1、支持覆盖、重复率、实际样本暴露 |
| 非针对性匹配控制 | 从已有 T 窗口选择、匹配变量及随机种子 | 同处理量和强度；尽量匹配时间、状态，列出未匹配差异 |
| 输入表示 | 已登记来源和变换 | 因果历史边界、训练/推理一致性、来源及无来源消融 |
| 删除 | T 掩码及剩余窗口 | 历史掩码重合、局部覆盖、其他工况代价 |

这些是候选规则族，尚非可执行候选池。第一版具体入选动作、强度、窗口阈值、匹配算法和控制身份必须在观察新候选响应前冻结。禁止 Agent 临时扩张动作或扫旧失败参数。随机抽取已有窗口属于衍生处理，不生成传感器记录。

配对方法固定初始化及随机数规则。采样分布改变时无法要求实际样本序列相同，须明确共享随机流与分布映射，保存真实样本呈现证据。确认重复数、种子及精度目标另待登记，不将三种子预设为充分证据。

## E1 信息边界与决策锁定

E1 是静态条件化选择。策略可见任务说明、获准的 T 摘要、固定基线 D 误差、预登记的基线训练动态，以及外层经验构建任务的获准记录。基线反馈属于候选干预前信息；获取成本计账。相同信息对照共享同一事实来源。

当前评价任务的任何候选响应、排序、胜者摘要及隐藏审计均不可见。候选响应可以已由评价者计算，但仍保留在策略不可访问的存储。E1 不提供请求当前任务候选结果的工具。策略先提交每个候选的效果预测或排序、关键候选对判断、不确定性/弃权、最终一个推荐、引用和可见信息清单，再锁定决策，之后才由评价器关联响应。弃权的最终可执行推荐须明示为不处理，不能省略。

历史中候选前状态无法恢复的记录可作背景；不得根据候选后结果补写为事前特征或预测。同一数据来源的已知答案进入上下文时标为经验复用分析，不称留出任务预测。当前 MetroPT3 缺少独立来源，不通过同源随机拆分伪造跨来源评价。

每次锁定记录内容哈希、锁定时间、策略及提示版本、经验库哈希、可见信息集哈希。输出解释不参与主要效果评分。记录格式见 [证据契约](EVIDENCE_CONTRACT.md) 与 [空白模板](record_templates.json)。模板不等于锁定收据；真实锁定由执行器保存不可覆盖的快照。

## 对照与信息表示

主对照为不处理、经验构建任务选出的最佳固定配方、简单案例匹配、浅层候选排序模型、普通 Agent、条件化 Agent。后两者共享基础 LLM、工具、推理配置和允许动作。服务只提供可变模型别名时保存请求和返回标识并披露限制，不宣称已严格固定权重快照。

固定配方仅在外层经验构建集合选择。非 LLM 模型的拟合、超参数选择及特征标准化均不得使用最终评价任务。浅层模型的具体算法和调参范围仍待登记。训练决策模型不改变冻结的 DLinear 预测骨干。

表示分两项独立比较：同一组信息的原始日志与结构化报告；整体摘要与额外覆盖、局部误差和训练动态。前者测组织方式，后者测新增信息。各版本的精确字段、上下文上限、截断规则和特征生成成本在运行前冻结。相同字段不能通过推荐式措辞暗示答案。

## 评价与不确定性

主比较为 V(pi)=mean_e[L_e(a_fixed)-L_e(pi(x_e))]，正值支持条件化选择。L 使用任务冻结的 NMSE，按任务先聚合训练重复，再按预登记任务/来源权重汇总。损失差与相对改善百分比同时区分报告。跨来源权重与重复数当前未定，不由结果决定。

同时报告相对不处理的确认有效率、伤害率、NMAE 约束满足率、弃权率及实际成本。平均收益不能抵消约束违规。NMAE 的逐任务/逐种子/均值约束方式、NMSE 最小实质增益、伤害阈值和等效区间均待登记；signal v2 的阈值不自动移植。

候选对仅在合格证据支持可区分时计算方向准确率，并报告可判定覆盖率。无法区分不强制唯一胜者；确认等效须落在预登记实质等效范围并满足不确定性标准，统计不显著不等于等效。

G_C=E_e[max_a Delta_e(a)]-max_a E_e[Delta_e(a)] 只作有限候选池的概念性选择空间，候选池包含不处理。报告应分别列出处理排序差异的确认、使用充分任务内开发反馈选出的参考策略、只看事前状态的策略。带噪声最大值或开发选择后的确认表现，不称 G_C 的无偏估计或严格上界。

发现与确认使用分离训练重复，降低种子选择偏差；这不能消除反复使用相同 D 的数据选择偏差。独立来源审计另待数据。推断单位为来源/任务，不能将重叠窗口或种子当独立来源。主比较、多重比较处理、区间方法、重复精度和缺失处理需事前登记。

科学标签与执行状态分离。所有注册尝试保留；成功执行比例和端到端成功率分别报告，未启动、平台失败、代码失败、控制不合格、约束违规不免费替换。仅有单次分数不能自动标为确认有益或确认有害，科学标签须引用配对确认集合及裁决规则。

## E2 探针衔接

进入条件是存在可确认的处理差异，并有可检验理由认为允许探针可提供与选择相关的信息；不要求静态预测已成功。该理由应给出不同可能响应及对应选择变化，而非只提供机制解释文字。

先在相同决策前缀、相同已执行探针、相同可选候选集下分叉完整响应、仅整体分数、屏蔽响应。分叉后独立继续，不共享完整反馈分支的未来动作、检索和排序。完整与屏蔽比较反馈价值，完整与总分比较诊断维度的增量。三者共享执行事实及相同执行/合法性状态，不把程序失败当科学响应。

先锁定首个反馈后的推荐来测直接选择变化；若继续执行，另设共同成本节点与独立续跑规则评价端到端效应。响应中稳定性维度只能来自该节点实际已付费完成的重复，不能免费提供未来确认。

候选发现、反馈利用、跨候选诊断分别报告。探针成为最终推荐不否定信息价值。跨候选预测集合事前划定，不事后剔除赢家。固定探针与自适应探针的选择能力比较，在验证反馈使用之后另行登记。

I(q)=E[L_audit(a_masked)-L_audit(a_feedback)] 仅表示所设对照下的经验选择改善，不是互信息或最优实验价值估计。当前缺隐藏审计时，只能用明确标注的开发确认指标报告探索结果，不填写虚构 audit 值。

## E3 经验衔接

经验更新记录适用条件的增加、删除、收紧或分裂，以及更新前后规则、证据与行为变化；仅提高置信度不算已学习适用边界。同时评价拒绝错误迁移与保留正确复用，避免将全面保守误称迁移更准确。新来源评价时经验构建、策略选择、最终评价按来源隔离；不将最终审计结果写回当前批次经验。

## 成本与分支推进

不恢复累计资源上限；单作业契约继续有效。物理成本和缓存重放的逻辑成本分开，基线、诊断、候选、控制、决策策略和复验均记账。成本节点由预登记账本维度定义；节点上保存当时最新已锁定推荐及累计成本，不能用未来反馈回填，未覆盖节点标为未覆盖。价格或成本换算规则需冻结，未知费用保持未知。

| 观察 | 下一步 |
|---|---|
| 排序差异证据不足 | 补重复或真实条件覆盖，不直接归因于 Agent |
| 排序差异存在、静态可预测 | 继续条件化选择，再检验探针增量 |
| 排序差异存在、静态难预测 | 可做小规模探针可识别性实验 |
| 非 LLM 与 Agent 相当 | 保留数据决策结论，开放构造另研究 |
| 完整反馈优于总分、自适应探针无优势 | 保留反馈表示贡献，不宣称探针选择有效 |
| 伤害降低但正确复用大量丢失 | 标为更保守，继续检查迁移权衡 |
| 隔离来源上的选择改善 | 再考虑外层策略优化与组合处理 |

证据不足不是永久禁用方法族的依据；已测失败配方仍保留原边界，不因本草案重跑旧 ID。
