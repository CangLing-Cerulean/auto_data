# 固定模型下的数据处理有效性研究

2026-10-09。本轮已取得符合事前判据的受控开发成果，并按用户要求停止探索。三个额外确认种子上，输入数据变换使平均 NMSE 从 **0.2871756451 降至 0.2750036930，改善 4.2385%**；平均 NMAE 从 0.1947745266 升至 0.1948799712，**退化 0.0541%**，满足预登记的平均退化不超过 1% 约束。来源扰乱、无来源消融和统一训练步数审计支持来源变化信息具有额外预测价值。

## 本轮回答的问题

“找到正确信号”分为三个可核查层次：现象能否复算；针对现象提出的处理是否按事前标准改善预测；控制和消融是否排除具体竞争解释。语言解释或发现分布差异本身不构成有效发现。事实诊断、处理有效性与机制支持分别保留证据。

本轮由主研究助手直接研究，使用历史经验；不计为自组 Agent 的自主发现成功。所有训练、推理、统计与检查均在专用 RTX 4090 服务器完成。本地承担编辑、上传、下载和资产复核。

## 诊断与处理

首轮[诊断报告](../../direct_diagnostics/20261009/REPORT.md)复算了三个历史基线。近期数字状态切换窗口占开发窗口约 15.47%，贡献约 40.05% 平方误差；Oil_level 恒定历史组的三个基线均劣于末值预测。这说明存在可测量的预测不足，但不能据此判断传感器故障或确定物理原因。本轮没有对这些现象逐一提出已验证的修复结论。

本次有效候选针对历史 A009 已提示的跨通道时间变化信息不足：保留自身末值，将自身变化与固定来源通道的变化各取一半。来源映射继承历史开发经验，本轮新增的是保留自身历史的混合处理及完整确认链。来源映射本身不属于本轮新发现。

                    + 0.5 × (来源历史 − 来源末值)

## 事前标准与确认结果

[有效性协议](EVIDENCE_PROTOCOL.md)在新处理训练前固定事实、主指标、局部指标、代价、控制与否定条件。两个训练内部时间原点须同时改善；随后[冻结](freeze_wave1.json)配方，探索种子 2026 单独保留，额外三个种子 3026、3027、3028 全部执行，不能按结果挑选种子。

## 哪些竞争解释得到检验

1. **来源时间对齐是否有价值。** 来源扰乱控制保留每个窗口的来源观测集合及自身历史比例，扰乱来源时间对齐并重新锚定末值。候选在三个额外种子均优于控制，平均 NMSE 改善 **8.7661%**。此控制没有保持全部输入统计量，单独不能确定唯一机制。
2. **是否只是缩小自身变化有效。** 额外登记并完成五次无来源消融：同样将自身变化缩小一半，删除来源项。候选在两个原点及三个确认种子均更好；三个确认种子相对这个消融平均 NMSE 再改善 **4.4276%**。[消融结果](mechanism_result.json)。该消融在探索种子开发结果之后登记，时间顺序见[登记记录](MECHANISM_ABLATION.md)。
3. **是否仅由最佳检查点时刻不同造成。** 对三个额外种子的四种方法统一使用第 3000 步检查点，无新增训练。候选较基线平均改善 **4.1524%**，较无来源消融改善 **4.3836%**，各确认种子方向一致。[审计结果](common_step_audit.json)。
4. **是否无关分支训练也发生变化。** 同一步数下，未处理九个通道的最终模型权重在各配对方法间完全一致；样本呈现次数及抽样身份均有收据。收益可以定位于改动的输入分支，而非额外参数、增加训练量或删除困难评价样本。

这些证据支持“来源变化信息能改善当前固定模型的预测”及对应处理的有效性。它们尚未证明传感器物理故障、唯一因果机制、任意数据集适用或 Agent 已能自主发现。

## 结论范围与停止决定

用户允许继续使用原有数据，因此本轮完成的是 MetroPT3 上的**受控开发成果**。历史映射和现有开发分区曾参与探索；两个内部时间原点与三个随机种子提供重复和控制证据，不能充当新的独立数据集。已在 2026-10-02 揭示的旧测试本轮未读取，不能继续称为未见测试。

历史完全替换来源方案在单种子 NMSE 上曾有更大收益并伴随更大 NMAE 代价，因此本轮不声称历史最优或 SOTA。当前成果是一个通过事前门槛、可复算且有针对性消融支持的数据变换方案，以及可用于后续研究的信号证据链。

有效性标准、处理确认和机制检查均已完成，按“取得有效成果后停止”的要求结束本轮探索，无后台训练队列。自组 Agent 正式发现仍暂缓；未来是否能复用这套诊断与干预证据，需要单独的固定预算重复运行及同预算对照。
