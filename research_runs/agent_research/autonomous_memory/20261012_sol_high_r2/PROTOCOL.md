# 完整历史经验驱动的 Sol high 自主探索 R2

用户在首轮融合试验后明确要求复用历史经验，让 Agent 自行探索，并确认开始。此阶段替代预列候选矩阵：方案、诊断、处理代码、修订和停止由 Sol high 决定，主研究助手仅维护边界、执行、验收与归档。DeepSeek API 关闭。内部模型成本不可见，不能记为免费。

## 固定边界

只用 MetroPT3 v1 原训练分区 T 和原开发分区 D，32 条历史预测随后 8 条记录，间断大于 30 秒或跨分区的窗口禁止。模型为原 individual DLinear，7920 参数、3000 步、batch 256、lr .001、weight decay 0、kernel 25；每 500 步在完整 D 上选择最佳检查点。T 拟合预处理，D 只由可信评价器产生指标。禁止测试、ground_truth、模型结构搜索或新增传感器数据。

允许自行编写诊断、保留/删除/权重/采样、因果输入表示处理，以及复现、组合、推翻历史方法；不限制方法族或预列候选。使用既有执行器的单任务时限、形状、有限数值、覆盖率、源行映射和代码边界校验，无候选数、调用数、总时间、训练数或累计 token 配额。重复删除校验为防止无意重复；明确的有目的复现应独立登记理由，不能被当作新发现。

## 历史经验与可见性

完整提供冻结 memory/v2 的 134 条运行收据及 10 条条件性解释，并补充后续直接数据处理、诊断、工程验收及 R1 成败证据。补充原文按 SHA256 登记；经验是条件性事实，不是方法禁令。旧 signal-v2 尚未完成语义验收，其机器状态仅作未验收记录。已知 source-half 配方允许复用，但复用收益不能宣称重新自主发现该配方。报告中提及旧测试的存在不授权读取数值或原始测试文件。

## 逐步闭环与最终确认

每次只接受一个 JSON 工具决定，保存实际上下文、决定、代码哈希、执行收据、失败及结果后更新。每个候选和机制控制先登记后执行；已有冻结记录不改写。Agent 自主提交 B0 或 NMAE 不超过 B0 1% 的最低开发 NMSE 候选。探索种子 2026101201。

最终配方冻结后，若探索 NMSE 改善至少 1% 且 NMAE 退化不超过 1%，运行三个额外种子 2026101202、2026101203、2026101204 的 B0、候选及已登记匹配控制。确认要求所有种子 NMSE 改善、平均改善至少 1%、平均 NMAE 退化不超过 1%。登记的局部改善门槛至少 3%；相对控制平均 NMSE 优势至少 .25% 且局部更好，并经语义审查，才讨论机制支持。缺少控制时只报告处理有效性，不补造机制证据。确认结果不返回搜索。没有达标候选则诚实结束本轮，不为了耗完预算继续。

本轮属于已知数据上的经验复用开发研究，不能证明独立泛化、从零发现或 LLM 反馈的因果优势。旧测试已揭示且严格隔离；旧成果不重写。完成阶段必须记录成本、报告和失败并同步现有 GitHub 仓库；大型模型资产用同仓库 Release。
