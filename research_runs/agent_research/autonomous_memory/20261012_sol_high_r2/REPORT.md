# Sol high 完整历史经验自主探索 R2

本轮完成了自主诊断、处理代码生成、反馈更新、冻结提交和三种子确认。候选相对 B0 的平均 NMSE 改善 **3.9409%**，NMAE 改善 **0.3616%**；相对历史全正号 source-half 对照，候选 NMSE 退化 **0.3842%**，登记局部 NMSE 退化 **13.1094%**。因此处理整体有效，但本轮新增的两个来源符号翻转未获支持，不能把历史配方的收益计为新增机制发现。

## 任务与自主范围

Sol high 获得冻结 memory/v2 的144条经验索引和10份补充原文，按需检索证据；没有预列候选或累计资源配额。实际模型为内部 gpt-6.1-sol / high；旧配置中的 reasoning_effort 字段属于未调用的外部API路径，见 [运行说明](actual_llm_runtime.json)。Agent 完成1次准备与11次工具决定，自主生成1个候选、匹配控制并决定停止。主助手负责执行、安全边界、工程恢复及最终验收，未向 Agent 返回确认指标。

使用 MetroPT3 v1 原 T/D，32条输入预测8条记录；合法 T 窗口1,053,433个、D窗口300,535个。固定 individual DLinear、7920参数、3000步、batch256、lr .001、kernel25、weight decay0，每500步由完整D选择最佳检查点。每次完整训练抽样768,000次，同种子同概率的抽样计数一致，55项训练资产哈希全部通过。服务器仅提供T/D，已校验其哈希、manifest与受保护代码，不能声称运行了完整三分区校验。没有测试访问或新增传感器记录。

Agent 首先检查来源变化的时间相位，发现六通道汇总的局部缺口很小，纠正了把全15通道总体值误当六通道总体对照的风险。全量T诊断超时后，独立登记固定抽样诊断，按三个时间块各最多8192个合法窗口计算关联；随后收缩到来源符号假设。过程及证据引用见 [决定摘要](decision_summary.json)。历史映射和半混合来自已有成果，不能称为本轮重新发现。

## 配方与确认结果

对历史六个目标通道，处理保持各自末值锚点，加0.5倍自身过去偏移及0.5倍来源过去偏移。候选仅将 TP2、DV_eletric 的来源系数改为 -0.5；匹配控制全部为 +0.5。处理器只读取原始过去输入并写克隆输出，保留全部窗口、均匀采样和原目标。两者均通过17个真实T窗口的CPU/CUDA边界检查。代码与状态见 [recipe](recipe/candidate/processor.py) 和 [事前控制审查](control_semantic_review.json)。

## 失败、恢复与成本

共12次训练尝试，11次完成、1次失败；相对阶段前217次，累计完整训练为228次。训练进程913.963233秒，含失败64.636504秒和恢复75.409093秒；额外分组评估106.243667秒。2次诊断共33.201951秒，其中1次超时；候选/控制构建共4.882516秒，处理器检查共4.735877秒。分类见 [cost_summary.json](cost_summary.json)，不把进程时间等同计费GPU占用或会话总墙钟时间。

最后一个控制因NATIVE_OUTPUT_TYPE被监控终止。确定性回归复现了枚举后临时文件原子重命名的误报，修复通过7项测试，包括字节/文件上限、符号链接、FIFO与权限异常。原事件未记录到系统调用级细节，缺陷与故障吻合但无法完全确定原始因果。冻结服务器源码未覆盖；修复只在恢复控制器内存生效，新增受保护资产生成新作业ID，科学身份完全一致。原失败与成本保留，见 [工程修订](engineering/amendment.json)。早先SSH断线后的恢复只使用已完成缓存，没有重复训练，见 [传输恢复](confirmation_transport_recovery.json)。

本轮外部API调用与tokens均为0；内部Sol high成本不可见，不记为免费。历史外部账本保持2544次尝试、14389704个已知tokens，40条未知用量和347757预约tokens另列，旧计时没有重置。
