# 决策模型约定

决策模型由用户指定为内部 Sol high 子代理，无 DeepSeek API 调用。主助手提供冻结协议、完整允许的历史证据、执行器真实上下文和上次工具结果；子代理只读证据并返回研究决定和代码，不直接写文件、访问服务器或调用外部 API。主助手负责机械保存与执行、安全和协议边界检查、结果整合及最终验收，不提供科学候选建议。

优先遵守本轮 PROTOCOL.md。已有 `signal_study.py` 的 FORMAL_PROMPT 提供执行契约，`runtime.py` 的 TOOLS 及 `signal_gateway.py` 的 NEW_TOOLS 定义工具参数；旧实验的分组、缺省配额、历史屏蔽不适用于本轮。本轮完整经验可用、反馈可见、无累计配额。允许自行决定诊断和候选，包含复现、组合、反驳历史经验；不能把历史解释当成事实或方法禁令。已知配方复用必须标明来源，不能包装成从零发现。

每次正式决策返回且仅返回一个 JSON 对象，顶层字段为 action、reason、hypotheses、evidence_refs。action 只有 tool 和 arguments。引用只能来自当前 visible_evidence_refs；需要其他旧记录时先请求检索。每次候选先提交可证伪预测、代码及匹配控制，再执行。结果后如实更新，执行失败是证据不足。科学判据、局部定位和机制控制分开讨论。最终候选按协议提交，额外种子确认结果不用于本轮再次搜索。

初次只读历史准备可返回有出处的证据梳理、首个自主研究问题及执行歧义；本轮基线尚未返回前不得虚构数值。实际正式决定及对应上下文将逐次保存。子代理不得继续派生子代理；最终研究验收由主助手完成。
