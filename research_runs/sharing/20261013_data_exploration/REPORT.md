## 摘要

本研究考察：在预测模型及训练协议固定时，如何根据数据与模型误差定位不足，提出数据干预，并在看到完整候选训练结果前预测其响应；进一步检验历史经验、反馈更新和廉价响应代理是否改善实际选择。研究覆盖MetroPT3、SKAB及UCI Hydraulic的冻结子版本，区分训练样本成员、损失权重、采样概率与输入表示四类干预。

现有实证包括：MetroPT3的来源变化混合输入在三个额外种子上平均NMSE降低4.2385%；SKAB选择任务S2的三点中值处理平均降低1.118270%；Hydraulic H1同一处理平均降低1.121626%。这些收益均有固定模型和开发评价的适用边界。一个C-only构建的均值漂移信号在SKAB两个任务的四个稳定响应格全部命中，却未迁移到Hydraulic。六支封存反馈回放中，完整方法对无信号、普通更新及仅整体反馈的新增选择收益均为零。

最新M1成对响应代理在三个Hydraulic同源开发分组上的响应预测MAE为0.407517个百分点，较固定父评分1.386154个百分点更低；但二者推荐完全相同，实际选择增量为零。原阶段数值审计失败保持，另立补验支持误差抵消和描述性成绩，未追改原阶段通过状态。截至快照累计完成331次完整训练；没有证据支持通用自主发现、反馈框架优势、SOTA或最终独立测试收益。下一项限定为同M1下的训练数据筛选开发问题，先冻结动作、概率/权重及强短训对照。

## 1. 研究问题、范围与自动化边界

1. **不足定位**：现象和局部预测误差能否独立复算？“少见、变化大、训练损失高”是否真的意味着应该删、降权或多采样？
2. **干预有效性**：处理是否改善整体预测，是否付出局部或NMAE代价，是否优于匹配控制？
3. **事前响应预测**：能否在完整子模型响应不可见时，预测改善、伤害、基本不变、不稳定及推荐收益？
4. **额外决策价值**：更复杂的诊断、历史复用、反馈或代理，是否优于简单规则、固定父评分和同预算真实短训练？

主线固定DLinear，不继续搜索网络结构。输入变换、训练成员关系、损失权重和采样概率分别记账；模型结构收益不计入数据处理。早期残差MLP的冻结测试NMSE改善29.2698%是独立模型成果，仅作背景，未纳入本文主结果。

自动化边界随阶段不同：直接处理研究由主研究助手指导；R2由Sol high自行诊断、生成候选/控制并提交，主助手负责执行、工程恢复和验收；共同池实验及M1由预登记执行器按固定清单运行。研究者的设计、协议和事后语义审查不冒称零人工参与，控制器顺序执行也不冒称Agent自主选择。近期研究LLM为内部`gpt-6.1-sol/high`，没有微调；DeepSeek已关闭。不同阶段信息权限详见各自协议。

## 3. 固定模型、训练、指标与接受条件

模型为individual DLinear，每通道独立seasonal/trend两个32→8线性层，移动平均核25、复制端点填充。15通道为7920参数，8通道为4224参数。保留原分支参数化和两个偏置，不把代理的等价表达当作改模型。

| 设置 | 固定值或规则 |
| --- | --- |
| 标准化 | 当前训练部分逐通道均值及总体标准差；零方差尺度置1 |
| 优化 | Adam，lr=0.001，weight_decay=0，batch=256 |
| 完整训练 | 3000次更新，768,000次窗口呈现 |
| 采样 | 默认均匀有放回；概率/损失权重动作另存各自p、w及实际计数 |
| 开发评价 | 每500步评价全部合法开发窗口，共六个检查点 |
| 模型选择 | 开发/B的NMSE严格更小才替换；精确并列保留更早检查点 |
| 配对 | 同种子同初始化，共同随机流；改变概率时样本索引可不同，实际抽样完整核验 |
| 最新工程环境 | RTX 4090；PyTorch 2.14.0+cu130；4个CPU线程；TF32关闭；float32参数、float64矩 |

NMSE是逐元素平方误差除以训练尺度平方后，对合法窗口×8预测位置×通道等权平均；NMAE为相应绝对误差归一化均值。主指标固定NMSE，NMAE为次指标/约束，不因结果换主指标。每种子改善率为`100×(1−candidate/paired_parent)`，正数表示误差下降。

**聚合规则必须按阶段保留**：直接处理及R2报告候选/基线三种子指标均值之比；阶段1、H1及M1按同种子相对改善率的算术平均。二者不混算。响应预测MAE单位是**百分点（pp）**，不是NMSE原值或绝对预测误差。

阶段1/H1响应分类为：改善率>+0.25%记improve，<-0.25%记harm，闭区间内unchanged；跨种子同时出现正、负带外响应记unstable_response。uncertain仅表示预测弃权，不能与unchanged混同。

处理确认一般要求三个额外种子的NMSE均改善、平均至少1%，并满足NMAE代价；直接处理的NMAE约束为三种子平均退化≤1%，阶段1/H1为每种子退化≤1%。0.25%分类带和1%采用门槛是不同判据，稳定小改善不自动采用。

## 5. 可复算诊断与有效输入处理

### 5.1 定位证据

在MetroPT3三个历史基线中，近期数字信号切换窗口占开发窗口约15.47%，贡献约40.05%平方误差；Oil_level恒定历史组连续多日均劣于持久性参照。模拟恒定组与长时距组高度重合，不能把重叠切片当两份独立原因证据。没有外部物理日志证实测量故障，不能直接据此删除传感器记录。

### 5.2 来源变化半混合

处理先以当前训练尺度标准化，再将六个目标通道的历史变为：

```text
x'_c(t) = x_c(last)
          + 0.5 × [x_c(t) − x_c(last)]
          + 0.5 × [x_source(c)(t) − x_source(c)(last)]
```

固定映射为TP2←TP3、TP3←DV_eletric、H1←TP3、Reservoirs←DV_eletric、Oil_temperature←Motor_current、DV_eletric←TP3，其余九列不变。仅用过去32条输入，目标不变，全量均匀采样。映射继承历史A009，本轮新增半混合与确认，未宣称从零发现映射。

### 5.3 自主历史复用R2

Agent读取冻结144条经验索引和10份补充证据，自行提出把TP2、DV_eletric来源系数由+0.5改为−0.5的候选。三个额外种子2026101202/03/04：B0/候选/全正号历史对照平均NMSE为0.28876956/0.27738949/0.27632796。

候选相对B0改善3.9409%、NMAE改善0.3616%，但相对历史对照整体NMSE退化0.3842%、登记局部退化13.1094%。F事实、P不足定位、L局部改善、E整体效果及U更新在各自登记范围通过，C增量控制失败；新增符号机制和完整自主可操作信号未建立。11次完成＋1次失败；单个自主上下文不足以估计自主发现率，三个模型种子也不是三次独立Agent搜索。[S5]

## 6. C构建、S预测与Hydraulic迁移

## 8. 事后机制与当前M1方法

### 8.1 固定处理和重训适应分解

用H1既有模型，令`e=父预测−目标`，`d=固定父模型因处理输入产生的预测变化`，`q=子模型预测−处理后父模型预测`。逐元素平方损失满足：

```text
L_child = L_parent + E[2ed] + E[d²] + E[2(e+d)q] + E[q²]
```

三个种子的best开发口径：P1固定处理贡献+1.454711%、重训适应−0.333084个百分点，总+1.121626%；CP1固定贡献−4.116139%、重训适应+3.829297个百分点，总−0.286842%。固定模型3000步last口径净方向反转：P1−0.366012%、CP1+1.258733%。这说明训练终点和选择规则必须纳入响应定义，不能拿last重选处理或覆盖best评分。24组事后分解不构成新事前预测或因果机制证明。[S10]

### 8.2 M1成对有限训练响应代理

M1保留每通道66维原seasonal/trend/偏置坐标，用A训练窗的加权全量矩计算期望梯度，并调用原Adam运行父/子代理3000步。每个真实父锚点作：

```text
θ̂_child,k = θ_real_parent,k + θ_proxy_child,k − θ_proxy_parent,k
```

按B在六个网格点选θ̂，在C预测相对真实父B最佳模型的完整子响应；完整真实子标签此前不可见。全量矩不等于随机小批量Adam或其期望，对相同期望梯度但不同采样噪声的动作可能不可辨别。基础平方误差恒等式与矩计算本身不作为创新。

四个同信息比较方法：M1、RAW未校正子代理、FIXED固定父模型在处理后C评分、SHORT同预算从同初始化真实短训。三任务×三种子2026101701/02/03，两个候选P1/CP1。选择预算每任务/种子30秒，SHORT各候选15秒；真实公共父、数据准备及标签审计另报，代理父成本不能省略。

方案提交`53c040a02a21df4f95c82d3478008748eda20764`先冻结；全部预测/推荐在`20ebe7f480083dc48d5101ac3bb0113fc03679a9`推送并锁定后，才运行18个完整真实子。目标是固定A/B训练与选择过程在C的响应，不是将A+B+C合并重训后的效果。[S11]–[S12]
