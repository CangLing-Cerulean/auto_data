# 固定 DLinear 数据筛选 Agent：开发协议 v1

本阶段实现 B0（全量）、B1（随机规则搜索）、A0（文本 Agent）。复用原 AgentController、SQLite Store、Repository、预算和可终止网络传输。运行对象是固定系统，独立运行清空记忆；不引用既有研究最优策略。原在线预测和发布程序保留其独立用途。

唯一基础数据为 metropt3_v1；T 和 D 沿用原训练、验证文件，不重划。准备与训练前执行 verify_dataset.py。旧测试和 ground_truth 没有工具入口。当前只有开发任务，不能证明独立泛化；新增独立数据需要另行登记协议和适配，禁止沿用旧测试作为 E。

训练复用 scripts.run_research.DLinear、prepare、evaluate，固定7920参数、原15列、32条→8条、间断超过30秒排除、完整训练行标准化、Adam .001、batch256、3000步。统一逆CDF均匀采样保留窗口，配对seed的随机流一致。每500步完整D评价，最小开发NMSE检查点；同分保留更早检查点。验证真值、窗口与评价尺度不随筛选改变。无中心化、补值、重采样到时间网格、模型搜索或权重轨道。

动作空间：all、训练特征比较（lt/le/gt/ge；训练分位数0..1或训练特征范围内字面阈值）、and/or（2..3子项）、not；最多7节点。特征为32条输入内标准化变化率、7模拟列的窗口整体均值/标准差、8数字列任一变化的相邻次数、真实经过天数、目标开始月份、输入末条8数字位编码及其状态×月份组的训练窗口数量。group_size可用于自主构造稀有组保护条件。规则不读目标值。

共同覆盖门槛为全局保留至少50%、每个数字状态×月份单元至少20%、总量不超过64的稀有单元全部保留。历史保存的整簇掩码、窗口概率和全分区采样概率中，提取去重后的删除成员集合，在共同行域上计算Jaccard，达到95%拒绝重复配方。这些是开发起点，正式协议前可通过新版本修改；不把程序保护当作Agent发现。

随机搜索与Agent使用同一语法、合法性检查、最多12个不同掩码的训练反馈。随机搜索最多60次规则提案：均匀选择单比较、双比较and、双比较or；特征、比较运算、分位数(.1,.25,.5,.75,.9)分别均匀。它在公共动作空间内采用已声明的随机分布，不声称均匀遍历所有表达式。重复掩码直接返回原成绩；非法规则不训练。Agent最多60次实际API请求（含重试、格式修复及收尾），token与时间共同限制。基线成本单独登记；实际训练和缓存命中均记录。

默认5次独立搜索/组。每次只提交一个程序选择的最终方案：满足NMAE最多退化1%，按开发NMSE最低选优，同分先基线、再先评估候选。Agent不能替换规则清单。预算到期提交已完成最佳合格方案；无优势保留全量。运行错误保存并计入全部预定运行分母，不删除失败记录。

DeepSeek Chat Completions使用deepseek-flash、reasoning_effort=low、JSON对象输出；收尾none。未设置在thinking模式无效的temperature。模型别名不能锁定服务端快照，记录返回模型、system fingerprint、使用量、日期和有效请求字段。提示词、工具、源码、任务、数据资产、配置及依赖版本由harness_manifest冻结。没有跨运行经验共享；相同配置/掩码/seed的确定性训练结果允许幂等复用，并披露缓存。

所有A0/B1预定运行提交后才允许freeze-batch。确认只使用新的2036/2037/2038训练种子，另设两类随机成员控制，每类成员seed20261021/22/23，控制是同数量或同分组配额随机子集。确认结果不进入Agent上下文。当前确认仍用D，因此只检查开发任务的训练随机性，绝不称为独立最终评价。确认GPU预算单独冻结，基线、筛选、诊断、API、缓存及端到端成本分别报告。

主比较为A0对B0/B1；没有图像组或小模型迁移的效果主张。视觉轨道可在后续另行冻结。NMSE改善1%、NMAE退化最多1%只作为当前开发成功阈值；正式独立评价的阈值需要预先登记。报告全部运行、失败、全量回退、合法提交、最差/中位收益；不把训练seed当独立Agent运行，不做重叠窗口独立性的显著性推断。

故障恢复仅重放已准备工具动作；已完成任务读取原收据。GPU任务保存优化器、采样状态和实际曝光量。失败/超时工作不自动重启，需显式平台故障审查；不允许策略修补后仍归为原自主运行。源码变化使旧manifest校验失败。原134次训练、已冻结MLP、研究预算账本和既有远程拒绝状态保持各自记录。
